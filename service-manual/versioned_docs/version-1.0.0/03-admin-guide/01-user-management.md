# 사용자 관리

시스템에 등록된 사용자를 효과적으로 관리하는 방법을 안내합니다. 사용자 추가 및 삭제, 역할 할당, 목록 관리, 일괄 처리 등 관리자가 수행해야 할 핵심 작업을 다룹니다.

## 사용자 추가

새로운 사용자를 시스템에 등록하는 방법입니다.

### 개별 사용자 추가

1. 관리자 패널에서 **사용자 관리** 메뉴로 이동합니다
2. **+ 사용자 추가** 버튼을 클릭합니다
3. 사용자 정보를 입력합니다:
   - **이메일**: 로그인에 사용할 이메일 주소
   - **이름**: 사용자의 표시 이름
   - **부서**: 소속 부서 선택
   - **역할**: 할당할 역할 선택
4. **초대 메일 발송** 체크박스를 선택합니다
5. **저장** 버튼을 클릭하여 등록을 완료합니다

:::tip
초대 메일을 발송하면 사용자가 직접 비밀번호를 설정할 수 있습니다. 초대 링크는 72시간 동안 유효합니다.
:::

### 사용자 등록 필수 항목

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 이메일 | 필수 | 로그인 ID로 사용, 중복 불가 |
| 이름 | 필수 | 시스템 내 표시 이름 |
| 부서 | 선택 | 조직 구조에 따른 소속 부서 |
| 역할 | 필수 | 접근 권한을 결정하는 역할 |
| 전화번호 | 선택 | 2차 인증 및 알림 수신용 |

## 사용자 삭제

시스템에서 사용자를 제거하는 방법입니다.

### 삭제 절차

1. **사용자 관리** 목록에서 삭제할 사용자를 선택합니다
2. 상단 메뉴의 **삭제** 버튼을 클릭합니다
3. 확인 대화상자에서 삭제 옵션을 선택합니다:
   - **즉시 삭제**: 사용자 계정을 즉시 비활성화
   - **유예 기간 삭제**: 30일 후 자동 삭제 (복구 가능)
4. **확인** 버튼을 클릭하여 삭제를 진행합니다

:::warning
즉시 삭제된 사용자의 데이터는 복구할 수 없습니다. 중요한 데이터가 있는 경우 유예 기간 삭제를 권장합니다.
:::

### 삭제 시 데이터 처리

| 데이터 유형 | 처리 방식 |
|-------------|-----------|
| 개인 설정 | 삭제됨 |
| 작성한 문서 | 보관됨 (관리자 접근 가능) |
| 프로젝트 참여 이력 | 보관됨 |
| 댓글 및 활동 로그 | 익명 처리 후 보관 |
| 업로드 파일 | 프로젝트 소유로 이전 |

## 역할 할당

사용자에게 적절한 역할을 할당하여 접근 권한을 관리합니다.

### 기본 역할 유형

| 역할 | 설명 | 주요 권한 |
|------|------|-----------|
| 시스템 관리자 | 전체 시스템 관리 권한 | 모든 기능 접근 |
| 프로젝트 관리자 | 프로젝트 단위 관리 권한 | 프로젝트 생성/삭제, 팀원 관리 |
| 일반 사용자 | 기본 사용 권한 | 작업 생성/수정, 문서 열람 |
| 뷰어 | 읽기 전용 권한 | 콘텐츠 열람만 가능 |

### 역할 변경 방법

1. 사용자 목록에서 대상 사용자를 클릭합니다
2. **역할** 탭을 선택합니다
3. 드롭다운에서 새로운 역할을 선택합니다
4. **변경 사유**를 입력합니다 (감사 로그용)
5. **적용** 버튼을 클릭합니다

:::note
역할 변경은 즉시 적용됩니다. 변경된 사용자는 다음 로그인 시 새로운 권한이 반영됩니다. 현재 세션 중인 경우 최대 5분 내에 반영됩니다.
:::

## 사용자 목록 관리

등록된 사용자를 효율적으로 조회하고 관리하는 방법입니다.

### 목록 필터링

사용자 목록에서 다양한 조건으로 필터링할 수 있습니다:

| 필터 조건 | 설명 |
|-----------|------|
| 상태 | 활성, 비활성, 대기 중, 잠금 상태별 필터 |
| 역할 | 특정 역할이 할당된 사용자만 표시 |
| 부서 | 특정 부서 소속 사용자만 표시 |
| 가입일 | 특정 기간 내 가입한 사용자 표시 |
| 마지막 로그인 | 최근 접속 기준 필터 |

### 목록 내보내기

사용자 목록을 외부 파일로 내보낼 수 있습니다:

- **CSV 형식**: 스프레드시트 프로그램에서 활용
- **Excel 형식**: 서식이 포함된 엑셀 파일
- **PDF 형식**: 인쇄용 보고서

## 일괄 관리

다수의 사용자를 한 번에 관리하는 기능입니다.

### 일괄 사용자 등록

CSV 파일을 사용하여 여러 사용자를 한 번에 등록할 수 있습니다.

```csv
이메일,이름,부서,역할
user1@example.com,홍길동,개발팀,일반 사용자
user2@example.com,김철수,마케팅팀,일반 사용자
user3@example.com,이영희,디자인팀,프로젝트 관리자
```

1. **사용자 관리** > **일괄 등록** 메뉴를 선택합니다
2. CSV 템플릿을 다운로드하여 사용자 정보를 입력합니다
3. 작성된 CSV 파일을 업로드합니다
4. 미리보기에서 데이터를 확인합니다
5. **일괄 등록** 버튼을 클릭합니다

:::danger
일괄 등록 시 이메일 중복 검사가 자동으로 수행됩니다. 중복된 이메일은 건너뛰며, 처리 결과 보고서에서 확인할 수 있습니다.
:::

### 일괄 작업 유형

| 작업 | 설명 | 최대 처리 수 |
|------|------|-------------|
| 일괄 등록 | CSV로 다수 사용자 등록 | 500명 |
| 일괄 역할 변경 | 선택한 사용자의 역할 일괄 변경 | 100명 |
| 일괄 비활성화 | 선택한 사용자 일괄 비활성화 | 100명 |
| 일괄 삭제 | 선택한 사용자 일괄 삭제 | 50명 |
| 일괄 초대 재발송 | 대기 중 사용자에게 초대 메일 재발송 | 200명 |

### 일괄 작업 이력 확인

모든 일괄 작업은 이력으로 기록됩니다:

1. **사용자 관리** > **일괄 작업 이력** 메뉴로 이동합니다
2. 작업 일시, 유형, 처리 건수, 실행자를 확인합니다
3. 각 작업의 상세 결과 보고서를 다운로드할 수 있습니다

:::tip
일괄 작업은 시스템 부하를 고려하여 업무 시간 외에 실행하는 것을 권장합니다. 예약 실행 기능을 활용하면 지정된 시간에 자동으로 처리됩니다.
:::
