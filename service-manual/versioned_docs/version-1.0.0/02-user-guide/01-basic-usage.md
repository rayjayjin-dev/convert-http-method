# 기본 사용법

서비스의 핵심 기능을 효과적으로 활용하기 위한 기본 사용법을 안내합니다. 대시보드 탐색부터 프로젝트 및 작업 관리까지 일상 업무에 필요한 기본 조작 방법을 다룹니다.

## 대시보드 사용

대시보드는 서비스에 로그인한 후 가장 먼저 표시되는 화면입니다. 주요 지표와 최근 활동을 한눈에 확인할 수 있습니다.

### 대시보드 구성 요소

| 구성 요소 | 설명 | 위치 |
|-----------|------|------|
| 요약 카드 | 프로젝트 수, 진행 중 작업, 완료율 등 핵심 지표 | 상단 영역 |
| 최근 활동 | 팀원들의 최근 작업 내역 타임라인 | 중앙 좌측 |
| 알림 패널 | 읽지 않은 알림 및 멘션 목록 | 중앙 우측 |
| 빠른 실행 | 자주 사용하는 기능 바로가기 버튼 | 하단 영역 |

### 대시보드 커스터마이징

대시보드 위젯을 사용자의 필요에 맞게 재배치할 수 있습니다.

1. 대시보드 우측 상단의 **편집** 버튼을 클릭합니다
2. 위젯을 드래그하여 원하는 위치로 이동합니다
3. 불필요한 위젯은 **×** 버튼으로 숨길 수 있습니다
4. **저장** 버튼을 클릭하여 변경사항을 적용합니다

:::tip
대시보드 레이아웃은 개인 설정으로 저장되며, 다른 기기에서 로그인해도 동일한 레이아웃이 적용됩니다.
:::

## 프로젝트 관리

프로젝트는 서비스의 핵심 단위입니다. 팀의 업무를 프로젝트 단위로 구성하여 체계적으로 관리할 수 있습니다.

### 프로젝트 생성

새 프로젝트를 생성하는 방법은 다음과 같습니다:

1. 좌측 사이드바에서 **프로젝트** 메뉴를 클릭합니다
2. **+ 새 프로젝트** 버튼을 클릭합니다
3. 프로젝트 정보를 입력합니다:
   - **프로젝트명**: 프로젝트를 식별할 수 있는 이름
   - **설명**: 프로젝트의 목적과 범위
   - **시작일/종료일**: 프로젝트 기간 설정
   - **팀원 초대**: 참여할 팀원 선택
4. **생성** 버튼을 클릭하여 프로젝트를 생성합니다

:::note
프로젝트 생성 권한은 관리자 또는 프로젝트 관리자 역할을 가진 사용자에게만 부여됩니다.
:::

### 프로젝트 목록 보기

프로젝트 목록에서는 다음과 같은 보기 모드를 지원합니다:

- **카드 보기**: 프로젝트를 카드 형태로 시각적으로 표시
- **리스트 보기**: 프로젝트를 테이블 형태로 상세 정보와 함께 표시
- **타임라인 보기**: 프로젝트 일정을 간트 차트 형태로 표시

### 프로젝트 상태 관리

프로젝트는 다음과 같은 상태를 가집니다:

| 상태 | 설명 |
|------|------|
| 준비 중 | 프로젝트가 생성되었으나 아직 시작되지 않은 상태 |
| 진행 중 | 프로젝트가 활성화되어 작업이 진행 중인 상태 |
| 보류 | 일시적으로 작업이 중단된 상태 |
| 완료 | 모든 작업이 완료되어 종료된 상태 |
| 보관됨 | 완료 후 아카이브된 상태 |

## 작업 관리

작업(Task)은 프로젝트 내에서 수행해야 할 개별 업무 단위입니다.

### 작업 생성

```
프로젝트 선택 → 작업 탭 → + 새 작업 → 정보 입력 → 저장
```

작업 생성 시 입력할 수 있는 항목:

- **작업명**: 작업의 제목
- **설명**: 작업의 상세 내용 (마크다운 지원)
- **담당자**: 작업을 수행할 팀원
- **우선순위**: 긴급, 높음, 보통, 낮음
- **마감일**: 작업 완료 기한
- **라벨**: 작업 분류를 위한 태그

### 작업 상태 변경

작업의 진행 상태를 변경하려면:

1. 작업 카드를 클릭하여 상세 화면을 엽니다
2. 상태 드롭다운에서 새로운 상태를 선택합니다
3. 필요시 코멘트를 추가합니다

:::tip
칸반 보드에서는 작업 카드를 드래그 앤 드롭하여 상태를 빠르게 변경할 수 있습니다.
:::

### 작업 필터링 및 정렬

작업 목록에서 다양한 조건으로 필터링할 수 있습니다:

| 필터 조건 | 설명 |
|-----------|------|
| 담당자 | 특정 팀원에게 할당된 작업만 표시 |
| 상태 | 특정 상태의 작업만 표시 |
| 우선순위 | 특정 우선순위의 작업만 표시 |
| 마감일 | 기간 범위 내의 작업만 표시 |
| 라벨 | 특정 라벨이 지정된 작업만 표시 |

## 파일 첨부 및 공유

작업이나 프로젝트에 파일을 첨부하여 팀원과 공유할 수 있습니다.

### 지원 파일 형식

- 문서: PDF, DOCX, XLSX, PPTX, TXT
- 이미지: PNG, JPG, GIF, SVG
- 압축: ZIP, RAR
- 최대 파일 크기: 50MB

### 파일 첨부 방법

1. 작업 상세 화면에서 **첨부파일** 영역을 클릭합니다
2. 파일을 선택하거나 드래그 앤 드롭합니다
3. 업로드가 완료되면 파일 목록에 표시됩니다

:::note
업로드된 파일은 프로젝트 팀원 모두가 다운로드할 수 있습니다. 민감한 파일은 권한 설정을 확인하세요.
:::
