# 고급 기능

서비스의 고급 기능을 활용하면 반복 작업을 자동화하고, 복잡한 워크플로우를 구성하며, 외부 도구와 연동하여 업무 효율을 극대화할 수 있습니다.

## 자동화 규칙

자동화 규칙을 설정하면 특정 조건이 충족될 때 지정된 작업이 자동으로 실행됩니다.

### 자동화 규칙 생성

1. **프로젝트 설정** → **자동화** 탭으로 이동합니다
2. **+ 새 규칙** 버튼을 클릭합니다
3. 트리거 조건과 실행 동작을 설정합니다

### 트리거 유형

| 트리거 | 설명 | 예시 |
|--------|------|------|
| 상태 변경 | 작업 상태가 변경될 때 | 작업이 "완료"로 변경되면 |
| 담당자 변경 | 작업 담당자가 변경될 때 | 새 담당자가 지정되면 |
| 마감일 도래 | 마감일이 임박할 때 | 마감 3일 전 |
| 라벨 추가 | 특정 라벨이 추가될 때 | "긴급" 라벨이 추가되면 |
| 코멘트 추가 | 새 코멘트가 작성될 때 | 코멘트에 멘션이 포함되면 |

### 실행 동작

트리거 조건이 충족되면 다음 동작을 자동으로 실행할 수 있습니다:

- 담당자 자동 지정
- 상태 자동 변경
- 알림 발송
- 라벨 자동 추가/제거
- 하위 작업 자동 생성

:::tip
자동화 규칙은 최대 10개까지 중첩하여 복잡한 워크플로우를 구성할 수 있습니다. 단, 무한 루프가 발생하지 않도록 주의하세요.
:::

## 워크플로우 설정

워크플로우는 작업이 거쳐야 하는 단계를 정의합니다. 프로젝트 특성에 맞게 커스텀 워크플로우를 구성할 수 있습니다.

### 기본 워크플로우

서비스에서 제공하는 기본 워크플로우 템플릿:

```
할 일 → 진행 중 → 검토 중 → 완료
```

### 커스텀 워크플로우 생성

1. **프로젝트 설정** → **워크플로우** 탭으로 이동합니다
2. **+ 새 워크플로우** 버튼을 클릭합니다
3. 단계를 추가하고 전환 규칙을 설정합니다

```
기획 → 디자인 → 개발 → QA → 배포 → 완료
```

### 전환 규칙 설정

각 단계 간 전환에 조건을 설정할 수 있습니다:

| 설정 항목 | 설명 |
|-----------|------|
| 전환 권한 | 특정 역할만 상태 전환 가능 |
| 필수 필드 | 전환 시 반드시 입력해야 하는 필드 |
| 승인 요청 | 전환 전 특정 사용자의 승인 필요 |
| 자동 알림 | 전환 시 관련자에게 자동 알림 발송 |

:::note
워크플로우 변경은 기존 작업에 소급 적용되지 않습니다. 변경 이후 생성되는 작업부터 새 워크플로우가 적용됩니다.
:::

## 통합 기능

외부 서비스와 연동하여 업무 환경을 통합할 수 있습니다.

### 지원 통합 목록

| 서비스 | 연동 기능 | 설정 방법 |
|--------|-----------|-----------|
| Slack | 알림 전송, 작업 생성 | Webhook URL 등록 |
| GitHub | 커밋 연결, PR 상태 동기화 | OAuth 인증 |
| Google Calendar | 마감일 동기화 | API 키 등록 |
| Jira | 이슈 양방향 동기화 | API 토큰 설정 |
| Email | 이메일로 작업 생성 | 전용 이메일 주소 할당 |

### 통합 설정 방법

1. **설정** → **통합** 메뉴로 이동합니다
2. 연동할 서비스를 선택합니다
3. 인증 정보를 입력하고 연결을 확인합니다
4. 동기화 옵션을 설정합니다

### Webhook 설정

외부 시스템에서 이벤트를 수신하기 위한 Webhook을 설정할 수 있습니다:

```json
{
  "url": "https://api.example.com/webhooks/incoming",
  "events": ["task.created", "task.updated", "task.completed"],
  "secret": "your-webhook-secret"
}
```

:::tip
Webhook 이벤트는 최대 3회까지 재시도됩니다. 수신 서버가 5초 내에 응답하지 않으면 타임아웃으로 처리됩니다.
:::

## 고급 필터링 및 검색

복잡한 조건을 조합하여 원하는 데이터를 정확하게 찾을 수 있습니다.

### 필터 조합

여러 조건을 AND/OR로 조합하여 복합 필터를 생성할 수 있습니다:

```
(담당자 = "김철수" OR 담당자 = "이영희")
AND 상태 != "완료"
AND 우선순위 = "높음"
AND 마감일 < "2024-12-31"
```

### 저장된 필터

자주 사용하는 필터 조합을 저장하여 빠르게 재사용할 수 있습니다:

1. 필터 조건을 설정합니다
2. **필터 저장** 버튼을 클릭합니다
3. 필터 이름을 입력하고 저장합니다
4. 사이드바의 **저장된 필터** 목록에서 클릭하여 적용합니다

### 검색 문법

고급 검색에서 사용할 수 있는 검색 문법:

| 문법 | 설명 | 예시 |
|------|------|------|
| `""` | 정확한 문구 검색 | `"배포 완료"` |
| `AND` | 모든 조건 충족 | `버그 AND 긴급` |
| `OR` | 하나 이상 조건 충족 | `프론트엔드 OR 백엔드` |
| `NOT` | 조건 제외 | `버그 NOT 해결됨` |
| `label:` | 라벨 기준 검색 | `label:긴급` |
| `assignee:` | 담당자 기준 검색 | `assignee:김철수` |

## 보고서 및 분석

프로젝트 진행 상황을 다양한 관점에서 분석할 수 있습니다.

### 기본 보고서 유형

- **번다운 차트**: 남은 작업량의 시간별 추이
- **번업 차트**: 완료된 작업량의 시간별 추이
- **속도 차트**: 스프린트별 완료 작업량 비교
- **분포 차트**: 상태/담당자/우선순위별 작업 분포

### 커스텀 보고서 생성

1. **보고서** 메뉴에서 **+ 새 보고서**를 클릭합니다
2. 데이터 소스와 기간을 선택합니다
3. 차트 유형과 그룹핑 기준을 설정합니다
4. **생성** 버튼을 클릭하여 보고서를 확인합니다

:::note
보고서 데이터는 실시간으로 업데이트됩니다. PDF 또는 Excel 형식으로 내보내기도 가능합니다.
:::
