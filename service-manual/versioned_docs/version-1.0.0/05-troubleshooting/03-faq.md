# 자주 묻는 질문 (FAQ)

서비스 이용에 관해 자주 문의되는 질문과 답변을 정리했습니다. 카테고리별로 원하는 내용을 확인하세요.

## 계정 관련

### 회원가입은 어떻게 하나요?

서비스 홈페이지에서 **회원가입** 버튼을 클릭하고 다음 정보를 입력합니다:

1. 이메일 주소 (로그인 ID로 사용)
2. 비밀번호 (8자 이상, 영문+숫자+특수문자 조합)
3. 이름 및 소속 정보
4. 이용약관 동의

가입 완료 후 입력한 이메일로 인증 메일이 발송됩니다. 이메일 인증을 완료해야 서비스를 이용할 수 있습니다.

:::tip
회사 이메일로 가입하면 소속 조직의 워크스페이스에 자동으로 초대될 수 있습니다.
:::

### 비밀번호를 잊어버렸습니다. 어떻게 재설정하나요?

1. 로그인 페이지에서 **비밀번호 찾기**를 클릭합니다
2. 가입 시 사용한 이메일 주소를 입력합니다
3. 이메일로 전송된 재설정 링크를 클릭합니다
4. 새 비밀번호를 설정합니다

:::note
비밀번호 재설정 링크는 발송 후 24시간 동안만 유효합니다. 만료된 경우 다시 요청하세요.
:::

### 계정을 삭제하고 싶습니다

계정 삭제는 **설정 > 계정 > 계정 삭제** 메뉴에서 진행할 수 있습니다.

:::warning
계정 삭제 시 모든 데이터가 영구적으로 삭제되며 복구할 수 없습니다. 삭제 전 필요한 데이터를 반드시 백업하세요. 삭제 요청 후 30일간의 유예 기간이 있으며, 이 기간 내에 로그인하면 삭제가 취소됩니다.
:::

### 이메일 주소를 변경할 수 있나요?

네, **설정 > 계정 > 이메일 변경**에서 새 이메일 주소로 변경할 수 있습니다. 변경 시 새 이메일 주소로 인증 메일이 발송되며, 인증을 완료해야 변경이 적용됩니다.

## 기능 관련

### 지원하는 브라우저는 무엇인가요?

다음 브라우저의 최신 2개 버전을 공식 지원합니다:

| 브라우저 | 최소 버전 | 권장 버전 |
|----------|-----------|-----------|
| Chrome | 90 이상 | 최신 버전 |
| Firefox | 88 이상 | 최신 버전 |
| Safari | 14 이상 | 최신 버전 |
| Edge | 90 이상 | 최신 버전 |

:::note
Internet Explorer는 지원하지 않습니다. 모바일 브라우저(Chrome Mobile, Safari Mobile)도 지원됩니다.
:::

### 오프라인에서도 사용할 수 있나요?

제한적으로 가능합니다. 오프라인 모드에서는 다음 기능을 사용할 수 있습니다:

- ✅ 이전에 열어본 문서 조회
- ✅ 임시 저장된 작업 편집
- ✅ 로컬 캐시된 데이터 검색
- ❌ 새 데이터 동기화
- ❌ 실시간 알림 수신
- ❌ 파일 업로드/다운로드

온라인 상태로 복귀하면 오프라인에서 변경한 내용이 자동으로 동기화됩니다.

### 데이터를 내보내기(Export)할 수 있나요?

네, 다음 형식으로 데이터를 내보낼 수 있습니다:

- **CSV** - 스프레드시트 호환 형식
- **JSON** - 프로그래밍 연동용 형식
- **PDF** - 문서 보관용 형식

내보내기 방법: **설정 > 데이터 관리 > 내보내기**에서 원하는 형식과 범위를 선택합니다.

:::tip
대량 데이터 내보내기는 시간이 소요될 수 있습니다. 완료 시 이메일로 다운로드 링크가 전송됩니다.
:::

### 알림 설정은 어떻게 변경하나요?

**설정 > 알림**에서 다음 항목을 개별적으로 설정할 수 있습니다:

| 알림 유형 | 이메일 | 푸시 | 인앱 |
|-----------|--------|------|------|
| 시스템 공지 | ✅ | ✅ | ✅ |
| 작업 할당 | 선택 | 선택 | ✅ |
| 댓글/멘션 | 선택 | 선택 | ✅ |
| 보안 알림 | ✅ | ✅ | ✅ |
| 마케팅 | 선택 | ❌ | ❌ |

## 결제 관련

### 어떤 요금제가 있나요?

| 플랜 | 월 요금 | 사용자 수 | 저장 공간 | 주요 기능 |
|------|---------|-----------|-----------|-----------|
| Free | 무료 | 최대 3명 | 1GB | 기본 기능 |
| Basic | ₩9,900/인 | 최대 10명 | 5GB | 고급 검색, 내보내기 |
| Pro | ₩19,900/인 | 최대 50명 | 50GB | API 접근, 커스텀 역할 |
| Enterprise | 별도 문의 | 무제한 | 무제한 | 전용 지원, SLA 보장 |

:::note
연간 결제 시 20% 할인이 적용됩니다. 모든 유료 플랜은 14일 무료 체험을 제공합니다.
:::

### 플랜을 변경하고 싶습니다

**설정 > 결제 > 플랜 변경**에서 언제든지 플랜을 변경할 수 있습니다.

- **업그레이드**: 즉시 적용되며, 남은 기간에 대해 일할 계산됩니다
- **다운그레이드**: 현재 결제 주기 종료 후 적용됩니다

:::warning
다운그레이드 시 현재 플랜에서만 제공되는 기능의 데이터가 제한될 수 있습니다. 변경 전 데이터를 백업하세요.
:::

### 결제 수단은 무엇을 지원하나요?

다음 결제 수단을 지원합니다:

- 신용카드/체크카드 (Visa, Mastercard, 국내 카드)
- 계좌이체 (기업 고객)
- 세금계산서 발행 (Enterprise 플랜)

### 환불 정책은 어떻게 되나요?

- 결제 후 7일 이내: 전액 환불
- 결제 후 7일 초과: 잔여 기간 일할 계산 환불
- 연간 결제: 사용 월수 차감 후 잔액 환불

환불 요청: **설정 > 결제 > 환불 요청** 또는 고객센터 문의

## 기술 관련

### API 연동은 어떻게 시작하나요?

1. **설정 > API > API 키 발급**에서 API 키를 생성합니다
2. [API 인증 가이드](/docs/api-reference/authentication)를 참고하여 인증을 설정합니다
3. [API 엔드포인트 목록](/docs/api-reference/endpoints)에서 필요한 API를 확인합니다

```bash
# API 연결 테스트
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.example.com/v1/health
```

:::tip
개발 환경에서는 Sandbox API 키를 사용하세요. Sandbox 환경에서는 실제 데이터에 영향을 주지 않고 API를 테스트할 수 있습니다.
:::

### Webhook을 설정하고 싶습니다

Webhook을 통해 서비스의 이벤트를 실시간으로 수신할 수 있습니다.

**설정 방법:**

1. **설정 > API > Webhook**으로 이동합니다
2. **새 Webhook 추가**를 클릭합니다
3. 수신 URL과 구독할 이벤트를 설정합니다
4. 시크릿 키를 저장합니다 (서명 검증용)

**지원 이벤트:**

| 이벤트 | 설명 |
|--------|------|
| `user.created` | 새 사용자 생성 |
| `user.updated` | 사용자 정보 변경 |
| `data.exported` | 데이터 내보내기 완료 |
| `payment.completed` | 결제 완료 |
| `system.alert` | 시스템 알림 |

### 서비스 가용성(SLA)은 어떻게 되나요?

| 플랜 | SLA | 월간 허용 다운타임 |
|------|-----|-------------------|
| Free / Basic | 99.5% | 약 3.6시간 |
| Pro | 99.9% | 약 43분 |
| Enterprise | 99.95% | 약 22분 |

서비스 상태는 [상태 페이지](https://status.example.com)에서 실시간으로 확인할 수 있습니다.

### 데이터는 어디에 저장되나요?

- **기본 리전**: 한국 (서울)
- **백업 리전**: 일본 (도쿄)
- **암호화**: AES-256 암호화 적용 (저장 시 및 전송 시)
- **백업 주기**: 매일 자동 백업, 30일간 보관

:::note
Enterprise 플랜에서는 데이터 저장 리전을 선택할 수 있습니다. 규정 준수(GDPR, 개인정보보호법)가 필요한 경우 별도 문의하세요.
:::

| 채널 | 운영 시간 | 응답 시간 |
|------|-----------|-----------|
| 이메일 (support@example.com) | 24시간 | 영업일 기준 24시간 이내 |
| 실시간 채팅 | 평일 09:00-18:00 | 즉시 |
| 전화 (1588-0000) | 평일 09:00-18:00 | 즉시 |
| 커뮤니티 포럼 | 24시간 | 커뮤니티 응답 |

:::tip
긴급한 시스템 장애의 경우 Enterprise 플랜 고객은 24시간 전용 핫라인을 이용할 수 있습니다.
:::
