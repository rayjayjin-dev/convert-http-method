# 빠른 시작 가이드

설치를 완료한 후 서비스를 빠르게 시작하는 방법을 안내합니다. 이 가이드를 따라하면 5분 이내에 첫 번째 작업을 수행할 수 있습니다.

## 사전 준비

빠른 시작을 위해 다음 사항이 준비되어 있어야 합니다:

- [x] 서비스 설치 완료
- [x] 관리자 계정 생성 완료
- [x] 브라우저에서 서비스 접속 가능

## 1단계: 로그인

1. 브라우저에서 서비스 URL에 접속합니다
2. 관리자 계정 또는 초대받은 계정으로 로그인합니다
3. 대시보드 화면이 표시되면 로그인 성공입니다

:::tip
최초 로그인 시 비밀번호 변경을 권장합니다.
:::

## 2단계: 첫 번째 프로젝트 생성

로그인 후 첫 번째 프로젝트를 생성합니다.

1. 좌측 메뉴에서 **프로젝트** 항목을 클릭합니다
2. **새 프로젝트 만들기** 버튼을 클릭합니다
3. 프로젝트 정보를 입력합니다:
   - **프로젝트명**: 프로젝트의 이름을 입력합니다
   - **설명**: 프로젝트에 대한 간단한 설명을 작성합니다
   - **공개 범위**: 팀 전체 또는 특정 멤버만 접근 가능하도록 설정합니다
4. **생성** 버튼을 클릭하여 프로젝트를 생성합니다

## 3단계: 팀원 초대

프로젝트에 팀원을 초대하여 협업을 시작합니다.

1. 프로젝트 설정 페이지로 이동합니다
2. **멤버 관리** 탭을 선택합니다
3. **멤버 초대** 버튼을 클릭합니다
4. 초대할 팀원의 이메일 주소를 입력합니다
5. 역할을 선택합니다:

| 역할 | 권한 |
|------|------|
| 뷰어 | 읽기 전용 |
| 편집자 | 읽기 및 쓰기 |
| 관리자 | 모든 권한 |

## 4단계: 첫 번째 작업 생성

프로젝트 내에서 첫 번째 작업을 생성합니다.

1. 프로젝트 대시보드에서 **작업 추가** 버튼을 클릭합니다
2. 작업 정보를 입력합니다:
   - **제목**: 작업의 제목을 입력합니다
   - **담당자**: 작업을 수행할 팀원을 지정합니다
   - **마감일**: 작업 완료 기한을 설정합니다
   - **우선순위**: 높음, 중간, 낮음 중 선택합니다
3. **저장** 버튼을 클릭합니다

:::note
작업은 생성 후에도 언제든지 수정할 수 있습니다.
:::

## 5단계: 결과 확인

생성한 프로젝트와 작업이 대시보드에 정상적으로 표시되는지 확인합니다.

- 대시보드에서 프로젝트 현황을 확인합니다
- 작업 목록에서 생성한 작업의 상태를 확인합니다
- 팀원이 초대 이메일을 수신했는지 확인합니다

## 다음 단계

빠른 시작을 완료했습니다. 더 자세한 사용법은 다음 문서를 참고하세요:

- **사용자 가이드 > 기본 사용법** - 서비스의 기본 기능을 상세히 알아봅니다
- **사용자 가이드 > 고급 기능** - 고급 기능을 활용하여 생산성을 높입니다
- **사용자 가이드 > 설정** - 개인 설정을 커스터마이즈합니다
- **사용자 가이드 > 단축키** - 단축키를 활용하여 빠르게 작업합니다

## 도움이 필요하신가요?

서비스 이용 중 궁금한 점이 있으시면 다음을 참고하세요:

- **문제 해결 > 자주 묻는 질문** 페이지에서 일반적인 질문에 대한 답변을 확인할 수 있습니다
- **문제 해결 > 일반적인 문제** 페이지에서 일반적인 문제의 해결 방법을 찾을 수 있습니다
