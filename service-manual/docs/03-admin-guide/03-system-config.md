# 시스템 설정

시스템의 전반적인 동작을 제어하는 설정 방법을 안내합니다. 전역 설정, 보안 정책, 백업 및 복원, 로그 관리 등 시스템 운영에 필요한 핵심 설정을 다룹니다.

## 전역 설정

시스템 전체에 적용되는 기본 설정을 관리합니다.

### 일반 설정

| 설정 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 사이트 이름 | 시스템 표시 이름 | 서비스 매뉴얼 |
| 기본 언어 | 시스템 기본 표시 언어 | 한국어 (ko) |
| 시간대 | 날짜/시간 표시 기준 | Asia/Seoul (UTC+9) |
| 날짜 형식 | 날짜 표시 포맷 | YYYY-MM-DD |
| 세션 타임아웃 | 비활동 시 자동 로그아웃 시간 | 30분 |
| 최대 업로드 크기 | 파일 업로드 최대 용량 | 50MB |

### 설정 변경 방법

1. **관리자 패널** > **시스템 설정** > **일반** 메뉴로 이동합니다
2. 변경할 설정 항목의 값을 수정합니다
3. **저장** 버튼을 클릭합니다
4. 일부 설정은 시스템 재시작 후 적용됩니다

:::note
시스템 재시작이 필요한 설정 항목은 저장 시 안내 메시지가 표시됩니다. 재시작 전까지는 이전 설정이 유지됩니다.
:::

### 알림 설정

시스템 알림의 발송 방식을 설정합니다:

- **이메일 알림**: SMTP 서버 설정 및 발송 템플릿 관리
- **인앱 알림**: 시스템 내 실시간 알림 설정
- **Webhook**: 외부 서비스 연동을 위한 웹훅 설정

```
SMTP 설정 예시:
  호스트: smtp.example.com
  포트: 587
  암호화: TLS
  인증: 사용
```

## 보안 정책

시스템의 보안 수준을 관리하는 정책 설정입니다.

### 비밀번호 정책

| 정책 항목 | 설명 | 권장값 |
|-----------|------|--------|
| 최소 길이 | 비밀번호 최소 문자 수 | 8자 이상 |
| 복잡도 요구 | 대/소문자, 숫자, 특수문자 조합 | 3가지 이상 조합 |
| 만료 기간 | 비밀번호 변경 주기 | 90일 |
| 이력 제한 | 이전 비밀번호 재사용 제한 | 최근 5개 |
| 실패 잠금 | 로그인 실패 시 계정 잠금 | 5회 실패 시 |
| 잠금 해제 시간 | 자동 잠금 해제까지 대기 시간 | 30분 |

### 2단계 인증 (2FA)

2단계 인증을 설정하여 보안을 강화할 수 있습니다:

1. **보안 정책** > **2단계 인증** 메뉴로 이동합니다
2. 인증 방식을 선택합니다:
   - **TOTP**: 시간 기반 일회용 비밀번호 (Google Authenticator 등)
   - **SMS**: 문자 메시지를 통한 인증 코드
   - **이메일**: 이메일을 통한 인증 코드
3. 적용 범위를 설정합니다:
   - 전체 사용자 필수
   - 관리자 역할만 필수
   - 선택적 사용

:::warning
2단계 인증을 전체 필수로 변경하면 미등록 사용자는 다음 로그인 시 2FA 설정을 완료해야 합니다. 변경 전 사전 공지를 권장합니다.
:::

### IP 접근 제어

특정 IP 주소 또는 대역에서만 시스템에 접근할 수 있도록 제한합니다:

| 설정 | 설명 |
|------|------|
| 허용 목록 (Whitelist) | 접근을 허용할 IP 주소/대역 목록 |
| 차단 목록 (Blacklist) | 접근을 차단할 IP 주소/대역 목록 |
| 관리자 전용 IP | 관리자 패널 접근 가능 IP 제한 |

:::danger
IP 접근 제어 설정 오류 시 모든 사용자의 접근이 차단될 수 있습니다. 설정 변경 시 반드시 현재 접속 IP가 허용 목록에 포함되어 있는지 확인하세요.
:::

## 백업 및 복원

시스템 데이터의 백업과 복원 방법을 안내합니다.

### 자동 백업 설정

| 설정 항목 | 설명 | 권장값 |
|-----------|------|--------|
| 백업 주기 | 자동 백업 실행 간격 | 매일 |
| 백업 시간 | 백업 실행 시각 | 03:00 (새벽) |
| 보관 기간 | 백업 파일 보관 일수 | 30일 |
| 백업 대상 | 백업에 포함할 데이터 범위 | 전체 (DB + 파일) |
| 저장 위치 | 백업 파일 저장 경로 | /backup 또는 외부 스토리지 |

### 백업 유형

- **전체 백업**: 데이터베이스와 업로드 파일을 포함한 전체 백업
- **증분 백업**: 마지막 백업 이후 변경된 데이터만 백업
- **설정 백업**: 시스템 설정 파일만 별도 백업

### 수동 백업 실행

1. **시스템 설정** > **백업 관리** 메뉴로 이동합니다
2. **즉시 백업** 버튼을 클릭합니다
3. 백업 유형과 대상을 선택합니다
4. 백업이 완료되면 알림을 받습니다

:::tip
시스템 업데이트나 대규모 설정 변경 전에는 반드시 수동 백업을 실행하세요. 문제 발생 시 빠르게 이전 상태로 복원할 수 있습니다.
:::

### 복원 절차

백업 데이터를 사용하여 시스템을 이전 상태로 복원합니다:

1. **백업 관리** > **백업 목록**에서 복원할 백업을 선택합니다
2. **복원** 버튼을 클릭합니다
3. 복원 옵션을 선택합니다:
   - **전체 복원**: 모든 데이터를 백업 시점으로 되돌림
   - **선택 복원**: 특정 데이터만 선택하여 복원
4. 확인 대화상자에서 **복원 시작**을 클릭합니다

:::danger
복원 작업은 현재 데이터를 덮어씁니다. 복원 전 현재 상태의 백업을 먼저 생성하는 것을 강력히 권장합니다.
:::

## 로그 관리

시스템 운영 로그를 조회하고 관리하는 방법입니다.

### 로그 유형

| 로그 유형 | 설명 | 보관 기간 |
|-----------|------|-----------|
| 접속 로그 | 사용자 로그인/로그아웃 기록 | 1년 |
| 활동 로그 | 사용자의 주요 작업 수행 기록 | 6개월 |
| 시스템 로그 | 시스템 이벤트 및 오류 기록 | 3개월 |
| 보안 로그 | 보안 관련 이벤트 (실패한 로그인 등) | 1년 |
| 감사 로그 | 권한 변경, 설정 변경 등 감사 대상 기록 | 2년 |

### 로그 조회

1. **시스템 설정** > **로그 관리** 메뉴로 이동합니다
2. 조회할 로그 유형을 선택합니다
3. 필터 조건을 설정합니다:
   - **기간**: 조회할 날짜 범위
   - **사용자**: 특정 사용자의 로그만 조회
   - **이벤트 유형**: 특정 이벤트만 필터링
   - **심각도**: 정보, 경고, 오류, 치명적 수준별 필터
4. **검색** 버튼을 클릭합니다

### 로그 내보내기

로그 데이터를 외부 시스템으로 내보낼 수 있습니다:

- **파일 내보내기**: CSV, JSON 형식으로 다운로드
- **Syslog 연동**: 외부 로그 수집 시스템으로 실시간 전송
- **SIEM 연동**: 보안 정보 및 이벤트 관리 시스템 연동

### 로그 보관 정책

:::note
로그 보관 기간이 경과한 데이터는 자동으로 삭제됩니다. 규정 준수를 위해 보관 기간을 변경해야 하는 경우, 스토리지 용량을 함께 고려하세요.
:::

로그 보관 정책을 설정하는 방법:

1. **로그 관리** > **보관 정책** 메뉴로 이동합니다
2. 각 로그 유형별 보관 기간을 설정합니다
3. 자동 삭제 또는 아카이브 방식을 선택합니다
4. **적용** 버튼을 클릭합니다

### 로그 알림 설정

특정 로그 이벤트 발생 시 관리자에게 알림을 보낼 수 있습니다:

| 알림 조건 | 설명 | 기본 설정 |
|-----------|------|-----------|
| 로그인 실패 반복 | 동일 계정 N회 이상 실패 | 5회, 즉시 알림 |
| 권한 변경 | 관리자 역할 권한 변경 시 | 즉시 알림 |
| 시스템 오류 | 치명적 오류 발생 시 | 즉시 알림 |
| 대량 데이터 삭제 | 일정 건수 이상 삭제 시 | 100건, 즉시 알림 |
| 비정상 접근 | 차단된 IP에서 접근 시도 | 즉시 알림 |

:::tip
알림 피로를 방지하기 위해 알림 조건의 임계값을 적절히 설정하세요. 너무 낮은 임계값은 불필요한 알림을 유발할 수 있습니다.
:::
