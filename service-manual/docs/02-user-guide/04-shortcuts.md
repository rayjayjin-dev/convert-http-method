# 단축키

키보드 단축키를 활용하면 마우스 조작 없이 빠르게 서비스를 사용할 수 있습니다. 기본 제공되는 단축키와 사용자 정의 단축키 설정 방법을 안내합니다.

## 단축키 개요

서비스는 다양한 키보드 단축키를 제공하여 업무 효율을 높여줍니다. 단축키는 크게 다음 카테고리로 분류됩니다:

- **전역 단축키**: 어떤 화면에서든 사용 가능
- **네비게이션 단축키**: 화면 간 이동
- **작업 단축키**: 작업 관련 조작
- **편집 단축키**: 텍스트 편집 시 사용

:::tip
단축키 목록을 빠르게 확인하려면 `Ctrl + /` (macOS: `⌘ + /`)를 누르세요. 현재 화면에서 사용 가능한 단축키 목록이 오버레이로 표시됩니다.
:::

## 전역 단축키

어떤 화면에서든 사용할 수 있는 기본 단축키입니다.

### Windows / Linux

| 단축키 | 동작 |
|--------|------|
| `Ctrl + K` | 빠른 검색 (커맨드 팔레트) 열기 |
| `Ctrl + /` | 단축키 도움말 표시 |
| `Ctrl + ,` | 설정 화면 열기 |
| `Ctrl + N` | 새 작업 생성 |
| `Ctrl + Shift + N` | 새 프로젝트 생성 |
| `Ctrl + B` | 사이드바 토글 |
| `Ctrl + Shift + F` | 전체 검색 |
| `Escape` | 현재 모달/패널 닫기 |
| `Ctrl + Z` | 마지막 작업 실행 취소 |

### macOS

| 단축키 | 동작 |
|--------|------|
| `⌘ + K` | 빠른 검색 (커맨드 팔레트) 열기 |
| `⌘ + /` | 단축키 도움말 표시 |
| `⌘ + ,` | 설정 화면 열기 |
| `⌘ + N` | 새 작업 생성 |
| `⌘ + Shift + N` | 새 프로젝트 생성 |
| `⌘ + B` | 사이드바 토글 |
| `⌘ + Shift + F` | 전체 검색 |
| `Escape` | 현재 모달/패널 닫기 |
| `⌘ + Z` | 마지막 작업 실행 취소 |

## 네비게이션 단축키

화면 간 이동을 위한 단축키입니다.

| 단축키 (Windows/Linux) | 단축키 (macOS) | 동작 |
|------------------------|----------------|------|
| `Alt + 1` | `⌥ + 1` | 대시보드로 이동 |
| `Alt + 2` | `⌥ + 2` | 프로젝트 목록으로 이동 |
| `Alt + 3` | `⌥ + 3` | 내 작업으로 이동 |
| `Alt + 4` | `⌥ + 4` | 알림 센터로 이동 |
| `Alt + 5` | `⌥ + 5` | 보고서로 이동 |
| `Alt + ←` | `⌥ + ←` | 이전 페이지로 이동 |
| `Alt + →` | `⌥ + →` | 다음 페이지로 이동 |
| `Tab` | `Tab` | 다음 항목으로 포커스 이동 |
| `Shift + Tab` | `Shift + Tab` | 이전 항목으로 포커스 이동 |

## 작업 관련 단축키

작업 목록 및 상세 화면에서 사용할 수 있는 단축키입니다.

### 작업 목록 화면

| 단축키 | 동작 |
|--------|------|
| `J` / `↓` | 다음 작업으로 이동 |
| `K` / `↑` | 이전 작업으로 이동 |
| `Enter` | 선택한 작업 상세 열기 |
| `Space` | 작업 선택/해제 (다중 선택) |
| `Ctrl + A` | 모든 작업 선택 |
| `X` | 선택한 작업 완료 처리 |
| `D` | 선택한 작업 삭제 |
| `L` | 라벨 추가 |
| `A` | 담당자 변경 |
| `P` | 우선순위 변경 |

### 작업 상세 화면

| 단축키 | 동작 |
|--------|------|
| `E` | 작업 편집 모드 전환 |
| `C` | 코멘트 입력란으로 포커스 |
| `S` | 상태 변경 드롭다운 열기 |
| `Ctrl + Enter` | 코멘트 저장 |
| `Ctrl + Shift + Enter` | 코멘트 저장 후 상태 변경 |
| `Escape` | 편집 취소 / 상세 닫기 |

:::note
작업 목록에서 `J`/`K` 키를 사용하려면 텍스트 입력 필드에 포커스가 없어야 합니다. 입력 필드에서 벗어나려면 `Escape`를 누르세요.
:::

## 커스텀 단축키 설정

기본 단축키를 사용자의 선호에 맞게 변경할 수 있습니다.

### 단축키 변경 방법

1. **설정** → **단축키** 탭으로 이동합니다
2. 변경할 단축키 항목을 찾습니다
3. 해당 항목의 **편집** 아이콘을 클릭합니다
4. 새로운 키 조합을 입력합니다
5. **저장** 버튼을 클릭합니다

### 단축키 설정 규칙

커스텀 단축키를 설정할 때 다음 규칙을 따라야 합니다:

:::warning 주의사항
- 브라우저 기본 단축키와 충돌하는 조합은 사용할 수 없습니다
- 하나의 키 조합에 여러 동작을 할당할 수 없습니다
- 수정자 키(Ctrl, Alt, Shift) 없이 단일 문자 키만으로는 전역 단축키를 설정할 수 없습니다
:::

### 단축키 충돌 해결

단축키 충돌이 발생하면 다음과 같이 해결합니다:

1. 충돌 알림이 표시됩니다
2. 기존 단축키를 유지하거나 새 단축키로 덮어쓸 수 있습니다
3. 충돌하는 기존 단축키는 자동으로 해제됩니다

### 단축키 초기화

모든 단축키를 기본값으로 되돌리려면:

```
설정 → 단축키 → 우측 상단 "기본값으로 초기화" 클릭
```

:::tip
단축키 설정은 계정에 저장되므로, 다른 기기에서 로그인해도 동일한 커스텀 단축키가 적용됩니다.
:::
