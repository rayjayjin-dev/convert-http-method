# 설정

서비스를 사용자의 업무 환경에 맞게 커스터마이징할 수 있습니다. 개인 프로필부터 알림, 테마, 언어까지 다양한 설정 옵션을 제공합니다.

## 설정 메뉴 접근

설정 화면에 접근하는 방법:

1. 우측 상단의 **프로필 아이콘**을 클릭합니다
2. 드롭다운 메뉴에서 **설정**을 선택합니다

또는 키보드 단축키 `Ctrl + ,` (macOS: `⌘ + ,`)를 사용하여 바로 접근할 수 있습니다.

## 개인 설정

### 프로필 정보

| 설정 항목 | 설명 | 필수 여부 |
|-----------|------|-----------|
| 이름 | 서비스에서 표시되는 사용자 이름 | 필수 |
| 이메일 | 로그인 및 알림 수신용 이메일 | 필수 |
| 프로필 사진 | 아바타 이미지 (최대 2MB) | 선택 |
| 직책 | 조직 내 직책 정보 | 선택 |
| 부서 | 소속 부서 정보 | 선택 |
| 연락처 | 추가 연락처 정보 | 선택 |

### 비밀번호 변경

1. **보안** 탭으로 이동합니다
2. 현재 비밀번호를 입력합니다
3. 새 비밀번호를 입력하고 확인합니다
4. **변경** 버튼을 클릭합니다

:::note
비밀번호는 최소 8자 이상이며, 영문 대소문자, 숫자, 특수문자를 각각 1개 이상 포함해야 합니다.
:::

### 2단계 인증 (2FA)

보안 강화를 위해 2단계 인증을 활성화할 수 있습니다:

1. **보안** 탭에서 **2단계 인증** 섹션을 찾습니다
2. **활성화** 버튼을 클릭합니다
3. 인증 앱(Google Authenticator 등)으로 QR 코드를 스캔합니다
4. 생성된 6자리 코드를 입력하여 설정을 완료합니다

## 알림 설정

알림을 세밀하게 제어하여 중요한 정보만 수신할 수 있습니다.

### 알림 채널

| 채널 | 설명 | 기본값 |
|------|------|--------|
| 인앱 알림 | 서비스 내 알림 센터에 표시 | 활성화 |
| 이메일 | 등록된 이메일로 알림 발송 | 활성화 |
| 브라우저 푸시 | 브라우저 푸시 알림 | 비활성화 |
| Slack | 연동된 Slack 채널로 알림 | 비활성화 |

### 알림 유형별 설정

각 이벤트 유형별로 알림 수신 여부를 개별 설정할 수 있습니다:

| 이벤트 | 인앱 | 이메일 | 푸시 |
|--------|------|--------|------|
| 작업 할당 | ✅ | ✅ | ✅ |
| 작업 상태 변경 | ✅ | ❌ | ❌ |
| 코멘트 멘션 | ✅ | ✅ | ✅ |
| 마감일 알림 | ✅ | ✅ | ✅ |
| 프로젝트 초대 | ✅ | ✅ | ❌ |
| 시스템 공지 | ✅ | ✅ | ❌ |

### 방해 금지 모드

특정 시간대에 알림을 일시적으로 차단할 수 있습니다:

1. **알림** 탭에서 **방해 금지** 섹션으로 이동합니다
2. 시작 시간과 종료 시간을 설정합니다
3. 적용할 요일을 선택합니다

:::tip
방해 금지 모드 중에도 "긴급" 라벨이 지정된 작업의 알림은 수신됩니다. 이 동작은 **예외 설정**에서 변경할 수 있습니다.
:::

## 테마 설정

서비스의 시각적 테마를 변경할 수 있습니다.

### 테마 모드

| 모드 | 설명 |
|------|------|
| 라이트 | 밝은 배경의 기본 테마 |
| 다크 | 어두운 배경의 다크 테마 |
| 시스템 | 운영체제 설정에 따라 자동 전환 |

### 테마 변경 방법

1. **외관** 탭으로 이동합니다
2. 원하는 테마 모드를 선택합니다
3. 변경사항이 즉시 적용됩니다

### 색상 커스터마이징

프로젝트별로 강조 색상을 변경할 수 있습니다:

```
설정 → 외관 → 강조 색상 → 색상 선택 또는 HEX 코드 입력
```

사용 가능한 프리셋 색상:

- 🔵 블루 (기본값)
- 🟢 그린
- 🟣 퍼플
- 🟠 오렌지
- 🔴 레드
- ⚫ 그레이

### 글꼴 크기 조정

콘텐츠 영역의 글꼴 크기를 조정할 수 있습니다:

| 크기 | 본문 | 제목 |
|------|------|------|
| 작게 | 13px | 20px |
| 보통 (기본) | 15px | 24px |
| 크게 | 17px | 28px |
| 매우 크게 | 19px | 32px |

## 언어 설정

서비스 인터페이스의 표시 언어를 변경할 수 있습니다.

### 지원 언어

현재 지원되는 언어 목록:

| 언어 | 코드 | 지원 범위 |
|------|------|-----------|
| 한국어 | ko | 전체 |
| English | en | 전체 |
| 日本語 | ja | UI만 |
| 中文 | zh | UI만 |

### 언어 변경 방법

1. **일반** 탭에서 **언어** 섹션을 찾습니다
2. 드롭다운에서 원하는 언어를 선택합니다
3. **저장** 버튼을 클릭합니다
4. 페이지가 새로고침되며 선택한 언어가 적용됩니다

:::note
언어 설정은 UI 인터페이스에만 적용됩니다. 사용자가 작성한 콘텐츠(작업명, 코멘트 등)는 원본 언어 그대로 표시됩니다.
:::

### 날짜 및 시간 형식

언어 설정에 따라 날짜와 시간 표시 형식이 자동으로 변경됩니다:

| 언어 | 날짜 형식 | 시간 형식 |
|------|-----------|-----------|
| 한국어 | 2024년 12월 25일 | 오후 3:30 |
| English | Dec 25, 2024 | 3:30 PM |
| 日本語 | 2024年12月25日 | 15:30 |

## 데이터 관리

### 데이터 내보내기

개인 데이터를 내보낼 수 있습니다:

1. **데이터** 탭으로 이동합니다
2. 내보낼 데이터 범위를 선택합니다
3. 형식(JSON, CSV)을 선택합니다
4. **내보내기** 버튼을 클릭합니다

### 계정 삭제

:::danger 주의
계정 삭제는 되돌릴 수 없습니다. 삭제 전 반드시 필요한 데이터를 백업하세요.
:::

계정을 삭제하려면:

1. **데이터** 탭에서 **계정 삭제** 섹션으로 이동합니다
2. 비밀번호를 입력하여 본인 확인을 합니다
3. 삭제 사유를 선택합니다
4. **계정 삭제** 버튼을 클릭합니다
