# 일반적인 문제

서비스 이용 중 자주 발생하는 문제와 해결 방법을 안내합니다. 각 문제별로 증상, 원인, 해결 방법을 확인하세요.

## 로그인 문제

### 로그인이 되지 않습니다

**증상:** 올바른 이메일과 비밀번호를 입력했지만 로그인에 실패합니다.

**원인:**
- 비밀번호 입력 시 Caps Lock이 활성화되어 있음
- 계정이 비활성화 또는 잠금 상태
- 브라우저 캐시/쿠키 문제

**해결 방법:**

1. Caps Lock 키가 꺼져 있는지 확인합니다
2. 비밀번호 재설정을 시도합니다
3. 브라우저 캐시와 쿠키를 삭제합니다
4. 시크릿/프라이빗 모드에서 로그인을 시도합니다

:::tip
5회 이상 로그인에 실패하면 계정이 자동으로 잠깁니다. 30분 후 다시 시도하거나 관리자에게 잠금 해제를 요청하세요.
:::

### 세션이 자주 만료됩니다

**증상:** 작업 중 갑자기 로그아웃되거나 세션 만료 메시지가 표시됩니다.

**원인:**
- 보안 정책에 의한 세션 타임아웃
- 여러 기기에서 동시 로그인
- 네트워크 연결 불안정

**해결 방법:**

1. 시스템 설정에서 세션 타임아웃 시간을 확인합니다
2. 다른 기기에서 로그아웃합니다
3. "로그인 상태 유지" 옵션을 활성화합니다

:::note
보안 정책에 따라 최대 세션 유지 시간이 제한될 수 있습니다. 관리자에게 정책 변경을 요청할 수 있습니다.
:::

## 성능 저하

### 페이지 로딩이 느립니다

**증상:** 페이지 전환 시 로딩 시간이 5초 이상 소요됩니다.

**원인:**
- 네트워크 대역폭 부족
- 브라우저 확장 프로그램 충돌
- 서버 부하 증가
- 로컬 캐시 손상

**해결 방법:**

1. 네트워크 연결 상태를 확인합니다
2. 불필요한 브라우저 확장 프로그램을 비활성화합니다
3. 브라우저 캐시를 삭제하고 새로고침합니다
4. 다른 브라우저에서 동일 증상이 발생하는지 확인합니다

```bash
# 네트워크 연결 상태 확인 (터미널)
ping api.example.com
traceroute api.example.com
```

### 검색 결과가 느리게 표시됩니다

**증상:** 검색어 입력 후 결과가 표시되기까지 오래 걸립니다.

**원인:**
- 검색 인덱스가 오래되었음
- 대량의 데이터가 인덱싱 중
- 복잡한 검색 쿼리 사용

**해결 방법:**

1. 검색어를 더 구체적으로 입력합니다
2. 필터를 활용하여 검색 범위를 좁힙니다
3. 관리자에게 검색 인덱스 재구축을 요청합니다

## 연결 오류

### 서버에 연결할 수 없습니다

**증상:** "서버에 연결할 수 없습니다" 또는 "네트워크 오류" 메시지가 표시됩니다.

**원인:**
- 인터넷 연결 끊김
- 서버 점검 중
- 방화벽 또는 프록시 설정 문제
- DNS 확인 실패

**해결 방법:**

1. 인터넷 연결 상태를 확인합니다
2. 서비스 상태 페이지에서 점검 여부를 확인합니다
3. VPN을 사용 중이라면 비활성화 후 재시도합니다
4. DNS 설정을 확인합니다

:::warning
회사 네트워크에서 접속하는 경우, 방화벽 정책으로 인해 특정 포트가 차단될 수 있습니다. IT 부서에 문의하여 필요한 포트(443, 8080)가 열려 있는지 확인하세요.
:::

### WebSocket 연결이 끊어집니다

**증상:** 실시간 알림이 수신되지 않거나 채팅 기능이 동작하지 않습니다.

**원인:**
- 프록시 서버가 WebSocket을 지원하지 않음
- 네트워크 타임아웃 설정이 너무 짧음
- 로드 밸런서 설정 문제

**해결 방법:**

1. 프록시 설정에서 WebSocket 지원을 활성화합니다
2. 네트워크 타임아웃 값을 늘립니다 (최소 60초 권장)
3. 브라우저 개발자 도구의 Network 탭에서 WebSocket 연결 상태를 확인합니다

## 데이터 동기화 문제

### 데이터가 동기화되지 않습니다

**증상:** 한 기기에서 변경한 내용이 다른 기기에 반영되지 않습니다.

**원인:**
- 동기화 서비스 일시 중단
- 충돌하는 변경 사항 존재
- 저장 공간 부족
- 오프라인 상태에서 변경 후 동기화 실패

**해결 방법:**

1. 동기화 상태 아이콘을 확인합니다 (🔄 동기화 중, ✅ 완료, ⚠️ 오류)
2. 수동 동기화를 실행합니다: **설정 > 동기화 > 지금 동기화**
3. 충돌이 발생한 경우 충돌 해결 화면에서 올바른 버전을 선택합니다
4. 저장 공간을 확인하고 필요시 불필요한 파일을 삭제합니다

:::tip
자동 동기화 간격은 기본 5분입니다. 실시간 동기화가 필요한 경우 **설정 > 동기화 > 동기화 간격**에서 1분으로 변경할 수 있습니다.
:::

### 파일 업로드가 실패합니다

**증상:** 파일 업로드 시 오류가 발생하거나 진행률이 멈춥니다.

**원인:**
- 파일 크기가 제한을 초과 (기본 최대 100MB)
- 지원하지 않는 파일 형식
- 네트워크 연결 불안정
- 저장 공간 할당량 초과

**해결 방법:**

1. 파일 크기가 업로드 제한 이내인지 확인합니다
2. 지원되는 파일 형식인지 확인합니다
3. 대용량 파일은 압축 후 업로드합니다
4. 저장 공간 사용량을 확인합니다: **설정 > 저장소 > 사용량**

| 플랜 | 최대 파일 크기 | 총 저장 공간 |
|------|---------------|-------------|
| Basic | 50MB | 5GB |
| Pro | 100MB | 50GB |
| Enterprise | 500MB | 무제한 |

## 문제가 해결되지 않는 경우

위 방법으로 문제가 해결되지 않으면 다음 정보를 포함하여 기술 지원팀에 문의하세요:

1. **문제 발생 시각** - 정확한 날짜와 시간
2. **사용 환경** - 운영체제, 브라우저 종류 및 버전
3. **재현 단계** - 문제를 재현할 수 있는 구체적인 단계
4. **에러 메시지** - 화면에 표시된 에러 메시지 전문
5. **스크린샷** - 문제 상황을 보여주는 화면 캡처

:::note
기술 지원 요청 시 브라우저 개발자 도구(F12)의 Console 탭에 표시된 에러 로그를 함께 첨부하면 더 빠른 해결이 가능합니다.
:::
