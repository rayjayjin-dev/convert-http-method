# 에러 메시지

서비스 이용 중 표시될 수 있는 에러 메시지와 해결 방법을 안내합니다. 에러 코드별로 원인과 조치 방법을 확인하세요.

## 에러 메시지 형식

서비스에서 표시되는 에러 메시지는 다음 형식을 따릅니다:

```
[에러 코드] 에러 설명
예: [E1001] 인증에 실패했습니다. 이메일 또는 비밀번호를 확인하세요.
```

:::tip
에러 코드를 기록해 두면 기술 지원 요청 시 빠른 문제 해결에 도움이 됩니다.
:::

## 인증 관련 에러 (E1xxx)

| 에러 코드 | 메시지 | 원인 | 해결 방법 |
|-----------|--------|------|-----------|
| E1001 | 인증에 실패했습니다 | 이메일 또는 비밀번호 불일치 | 입력 정보 확인 후 재시도 |
| E1002 | 계정이 잠겼습니다 | 로그인 5회 연속 실패 | 30분 대기 또는 관리자 문의 |
| E1003 | 세션이 만료되었습니다 | 장시간 미사용 | 다시 로그인 |
| E1004 | 접근 권한이 없습니다 | 해당 리소스에 대한 권한 부족 | 관리자에게 권한 요청 |
| E1005 | 토큰이 유효하지 않습니다 | API 토큰 만료 또는 폐기 | 새 토큰 발급 |
| E1006 | 2단계 인증이 필요합니다 | 보안 정책에 의한 추가 인증 요구 | 인증 앱에서 코드 확인 |

### E1001: 인증에 실패했습니다

**상세 설명:**

로그인 시 입력한 이메일 또는 비밀번호가 시스템에 등록된 정보와 일치하지 않을 때 발생합니다.

**해결 단계:**

1. 이메일 주소의 오타를 확인합니다
2. Caps Lock이 비활성화되어 있는지 확인합니다
3. 비밀번호 재설정을 시도합니다
4. 소셜 로그인으로 가입한 계정인지 확인합니다

:::warning
비밀번호를 5회 연속 틀리면 계정이 자동으로 잠깁니다 (E1002). 신중하게 입력하세요.
:::

### E1004: 접근 권한이 없습니다

**상세 설명:**

현재 로그인한 계정의 역할(Role)로는 요청한 리소스에 접근할 수 없을 때 발생합니다.

**해결 단계:**

1. 현재 계정의 역할을 확인합니다: **프로필 > 계정 정보 > 역할**
2. 필요한 권한을 관리자에게 요청합니다
3. 올바른 계정으로 로그인했는지 확인합니다

## 데이터 관련 에러 (E2xxx)

| 에러 코드 | 메시지 | 원인 | 해결 방법 |
|-----------|--------|------|-----------|
| E2001 | 데이터를 찾을 수 없습니다 | 요청한 리소스가 존재하지 않음 | URL 또는 ID 확인 |
| E2002 | 데이터 저장에 실패했습니다 | 서버 저장 오류 | 잠시 후 재시도 |
| E2003 | 입력값이 유효하지 않습니다 | 필수 필드 누락 또는 형식 오류 | 입력 양식 확인 |
| E2004 | 중복된 데이터가 존재합니다 | 고유 필드 값 중복 | 다른 값으로 변경 |
| E2005 | 데이터 크기가 초과되었습니다 | 입력 데이터가 허용 범위 초과 | 데이터 크기 축소 |
| E2006 | 참조 데이터가 삭제되었습니다 | 연결된 데이터가 이미 삭제됨 | 참조 관계 확인 |

### E2003: 입력값이 유효하지 않습니다

**상세 설명:**

폼 제출 시 필수 필드가 비어 있거나, 입력값의 형식이 올바르지 않을 때 발생합니다.

**일반적인 유효성 검증 규칙:**

| 필드 유형 | 규칙 | 예시 |
|-----------|------|------|
| 이메일 | RFC 5322 형식 | `user@example.com` |
| 전화번호 | 숫자와 하이픈만 허용 | `010-1234-5678` |
| 비밀번호 | 최소 8자, 영문+숫자+특수문자 | `MyP@ss1234` |
| 날짜 | ISO 8601 형식 | `2024-01-15` |
| URL | http:// 또는 https:// 시작 | `https://example.com` |

**해결 단계:**

1. 에러 메시지에 표시된 필드를 확인합니다
2. 필수 입력 항목(* 표시)이 모두 채워져 있는지 확인합니다
3. 입력 형식이 올바른지 확인합니다
4. 특수문자나 공백이 포함되어 있지 않은지 확인합니다

## 파일 관련 에러 (E3xxx)

| 에러 코드 | 메시지 | 원인 | 해결 방법 |
|-----------|--------|------|-----------|
| E3001 | 파일 업로드에 실패했습니다 | 네트워크 오류 또는 서버 문제 | 네트워크 확인 후 재시도 |
| E3002 | 파일 크기가 초과되었습니다 | 최대 허용 크기 초과 | 파일 압축 또는 분할 |
| E3003 | 지원하지 않는 파일 형식입니다 | 허용되지 않은 확장자 | 지원 형식으로 변환 |
| E3004 | 저장 공간이 부족합니다 | 할당된 저장 공간 초과 | 불필요한 파일 삭제 또는 플랜 업그레이드 |
| E3005 | 파일이 손상되었습니다 | 업로드 중 데이터 손상 | 원본 파일 확인 후 재업로드 |

### E3002: 파일 크기가 초과되었습니다

**상세 설명:**

업로드하려는 파일의 크기가 플랜별 최대 허용 크기를 초과할 때 발생합니다.

**플랜별 파일 크기 제한:**

| 플랜 | 단일 파일 최대 크기 | 일일 업로드 한도 |
|------|-------------------|-----------------|
| Basic | 50MB | 500MB |
| Pro | 100MB | 2GB |
| Enterprise | 500MB | 무제한 |

**해결 단계:**

1. 파일 크기를 확인합니다
2. 이미지 파일은 압축 도구를 사용하여 크기를 줄입니다
3. 대용량 파일은 ZIP으로 압축합니다
4. 플랜 업그레이드를 고려합니다

:::note
동영상 파일은 별도의 미디어 업로드 기능을 사용하세요. 일반 파일 업로드와 다른 크기 제한이 적용됩니다.
:::

## 네트워크 관련 에러 (E4xxx)

| 에러 코드 | 메시지 | 원인 | 해결 방법 |
|-----------|--------|------|-----------|
| E4001 | 서버에 연결할 수 없습니다 | 네트워크 연결 끊김 | 인터넷 연결 확인 |
| E4002 | 요청 시간이 초과되었습니다 | 서버 응답 지연 | 잠시 후 재시도 |
| E4003 | 요청 횟수가 초과되었습니다 | API Rate Limit 도달 | 잠시 대기 후 재시도 |
| E4004 | 서비스 점검 중입니다 | 정기/긴급 점검 | 점검 완료 후 재시도 |
| E4005 | SSL 인증서 오류 | 인증서 만료 또는 불일치 | 시스템 시간 확인, 관리자 문의 |

### E4002: 요청 시간이 초과되었습니다

**상세 설명:**

서버가 지정된 시간(기본 30초) 내에 응답하지 않을 때 발생합니다.

**해결 단계:**

1. 네트워크 연결 상태를 확인합니다
2. 페이지를 새로고침합니다
3. 대량 데이터 요청의 경우 필터를 적용하여 범위를 줄입니다
4. 반복 발생 시 기술 지원팀에 문의합니다

:::warning
타임아웃 에러가 반복적으로 발생하면 서버 부하가 높은 상태일 수 있습니다. 피크 시간대(오전 9-10시)를 피해 재시도하세요.
:::

## 시스템 관련 에러 (E5xxx)

| 에러 코드 | 메시지 | 원인 | 해결 방법 |
|-----------|--------|------|-----------|
| E5001 | 시스템 오류가 발생했습니다 | 서버 내부 오류 | 잠시 후 재시도, 반복 시 문의 |
| E5002 | 데이터베이스 연결 오류 | DB 서버 문제 | 관리자 문의 |
| E5003 | 외부 서비스 연동 오류 | 연동 서비스 장애 | 해당 서비스 상태 확인 |
| E5004 | 메모리 부족 | 서버 리소스 부족 | 관리자 문의 |
| E5005 | 설정 오류 | 시스템 설정 불일치 | 관리자 문의 |

### E5001: 시스템 오류가 발생했습니다

**상세 설명:**

서버 내부에서 예기치 않은 오류가 발생했을 때 표시됩니다. 사용자 측에서 직접 해결할 수 없는 경우가 대부분입니다.

**해결 단계:**

1. 5~10분 후 다시 시도합니다
2. 브라우저 캐시를 삭제하고 재시도합니다
3. 다른 브라우저에서 시도합니다
4. 문제가 지속되면 다음 정보와 함께 기술 지원팀에 문의합니다:
   - 에러 발생 시각
   - 수행하려던 작업
   - 에러 코드 및 메시지 전문

## 에러 코드 빠른 참조

에러 코드 범위별 카테고리:

| 코드 범위 | 카테고리 | 주요 조치 |
|-----------|----------|-----------|
| E1xxx | 인증/권한 | 로그인 정보 확인, 권한 요청 |
| E2xxx | 데이터 | 입력값 확인, 데이터 정합성 점검 |
| E3xxx | 파일 | 파일 크기/형식 확인 |
| E4xxx | 네트워크 | 연결 상태 확인, 재시도 |
| E5xxx | 시스템 | 관리자 문의, 잠시 후 재시도 |

:::note
에러 코드가 위 목록에 없는 경우, 서비스 업데이트로 새로운 에러 코드가 추가되었을 수 있습니다. 기술 지원팀에 해당 에러 코드를 문의하세요.
:::
