# 설치 방법

본 문서에서는 서비스를 설치하고 초기 설정을 완료하는 방법을 안내합니다.

## 시스템 요구사항

서비스를 원활하게 사용하기 위한 최소 시스템 요구사항은 다음과 같습니다.

### 하드웨어 요구사항

| 항목 | 최소 사양 | 권장 사양 |
|------|-----------|-----------|
| CPU | 2코어 이상 | 4코어 이상 |
| 메모리 | 4GB RAM | 8GB RAM 이상 |
| 디스크 | 20GB 여유 공간 | 50GB 이상 여유 공간 |
| 네트워크 | 10Mbps | 100Mbps 이상 |

### 소프트웨어 요구사항

- **운영체제**: Windows 10 이상, macOS 12 이상, Ubuntu 20.04 이상
- **브라우저**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Node.js**: 18.x 이상 (서버 설치 시)
- **데이터베이스**: PostgreSQL 14 이상 또는 MySQL 8.0 이상

## 설치 절차

### 1단계: 설치 파일 다운로드

공식 다운로드 페이지에서 운영체제에 맞는 설치 파일을 다운로드합니다.

```bash
# Linux/macOS 환경
curl -fsSL https://example.com/install.sh | bash

# 또는 패키지 매니저 사용
npm install -g @example/service-cli
```

### 2단계: 의존성 설치

프로젝트 디렉토리에서 필요한 의존성을 설치합니다.

```bash
# 프로젝트 디렉토리로 이동
cd my-project

# 의존성 설치
npm install
```

### 3단계: 환경 설정

환경 설정 파일을 생성하고 필요한 값을 입력합니다.

```bash
# 환경 설정 파일 생성
cp .env.example .env
```

주요 환경 변수 설명:

| 변수명 | 설명 | 기본값 |
|--------|------|--------|
| `APP_PORT` | 서비스 포트 번호 | 3000 |
| `DB_HOST` | 데이터베이스 호스트 | localhost |
| `DB_PORT` | 데이터베이스 포트 | 5432 |
| `DB_NAME` | 데이터베이스 이름 | service_db |
| `SECRET_KEY` | 암호화 키 | (필수 입력) |

### 4단계: 데이터베이스 초기화

데이터베이스 스키마를 생성하고 초기 데이터를 설정합니다.

```bash
# 데이터베이스 마이그레이션 실행
npm run db:migrate

# 초기 데이터 시드
npm run db:seed
```

### 5단계: 서비스 시작

모든 설정이 완료되면 서비스를 시작합니다.

```bash
# 개발 모드로 시작
npm run dev

# 프로덕션 모드로 시작
npm run start
```

## 초기 설정

서비스를 처음 시작한 후 다음 초기 설정을 완료해야 합니다:

1. **관리자 계정 생성**: 최초 접속 시 관리자 계정을 생성합니다
2. **조직 정보 입력**: 조직명, 로고, 기본 설정을 입력합니다
3. **사용자 초대**: 팀원을 초대하고 역할을 할당합니다
4. **알림 설정**: 이메일 및 알림 채널을 설정합니다

## 설치 확인

설치가 정상적으로 완료되었는지 확인하려면 다음 명령을 실행합니다:

```bash
# 서비스 상태 확인
npm run health-check

# 버전 정보 확인
npm run version
```

정상적으로 설치되었다면 브라우저에서 `http://localhost:3000`으로 접속하여 로그인 화면을 확인할 수 있습니다.

## 문제 해결

설치 중 문제가 발생하면 **문제 해결 > 일반적인 문제** 섹션을 참고하세요.
