# Quick Start Guide

This guide helps you get up and running quickly after installation. Follow these steps to complete your first task within 5 minutes.

## Prerequisites

Before starting, ensure the following:

- [x] Service installation complete
- [x] Admin account created
- [x] Service accessible via browser

## Step 1: Log In

1. Navigate to the service URL in your browser
2. Log in with your admin or invited account
3. The dashboard screen confirms a successful login

:::tip
We recommend changing your password on first login.
:::

## Step 2: Create Your First Project

After logging in, create your first project.

1. Click **Projects** in the left menu
2. Click the **Create New Project** button
3. Fill in the project details:
   - **Project Name**: Enter a name for the project
   - **Description**: Write a brief description
   - **Visibility**: Set access to the entire team or specific members
4. Click **Create** to finalize the project

## Step 3: Invite Team Members

Invite team members to start collaborating on the project.

1. Navigate to the project settings page
2. Select the **Members** tab
3. Click **Invite Member**
4. Enter the team member's email address
5. Select a role:

| Role | Permissions |
|------|-------------|
| Viewer | Read-only access |
| Editor | Read and write access |
| Admin | Full access |

## Step 4: Create Your First Task

Create your first task within the project.

1. Click **Add Task** on the project dashboard
2. Fill in the task details:
   - **Title**: Enter the task title
   - **Assignee**: Assign a team member
   - **Due Date**: Set the deadline
   - **Priority**: Choose High, Medium, or Low
3. Click **Save**

:::note
Tasks can be modified at any time after creation.
:::

## Step 5: Verify Results

Confirm that your project and task appear correctly on the dashboard.

- Check the project status on the dashboard
- Verify the task status in the task list
- Confirm that team members received invitation emails
