# Keyboard Shortcuts

Use keyboard shortcuts to navigate and operate the service quickly without a mouse. This guide covers default shortcuts and custom shortcut configuration.

## Overview

The service provides various keyboard shortcuts organized into the following categories:

- **Global Shortcuts**: Available on any screen
- **Navigation Shortcuts**: Move between screens
- **Task Shortcuts**: Task-related operations
- **Editing Shortcuts**: Text formatting

:::tip
Press `Ctrl + /` (macOS: `⌘ + /`) to quickly view available shortcuts for the current screen.
:::

## Custom Shortcuts

Customize default shortcuts to match your preferences.

### Changing Shortcuts

1. Navigate to **Settings** → **Shortcuts** tab
2. Find the shortcut to change
3. Click the **Edit** icon
4. Press the new key combination
5. Click **Save**

### Shortcut Rules

:::warning
- Browser default shortcuts cannot be overridden
- One key combination cannot be assigned to multiple actions
- Global shortcuts require at least one modifier key (Ctrl, Alt, Shift)
:::

### Resolving Conflicts

When a shortcut conflict occurs:

1. A conflict notification appears
2. Choose to keep the existing shortcut or override it
3. The conflicting shortcut is automatically unassigned

### Reset to Defaults

To reset all shortcuts to their default values:

```
Settings → Shortcuts → "Reset to Defaults" (top-right)
```

:::tip
Shortcut settings are saved to your account and persist across devices.
:::
