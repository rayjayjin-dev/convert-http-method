# 権限管理

このガイドでは、ロールベースアクセス制御（RBAC）モデルを使用したアクセス権限の体系的な管理方法、権限設定、カスタムロールの作成方法をご案内します。

## ロールベースアクセス制御（RBAC）

システムはロールベースアクセス制御を使用してユーザー権限を管理します。

### RBAC構造

```
組織
  └── ロール
        └── 権限
              └── リソース + アクション
```

### コア概念

| 概念 | 説明 | 例 |
|------|------|-----|
| ロール | 権限の論理的なグループ | システム管理者、編集者 |
| 権限 | リソースに対する許可されたアクション | ドキュメントの読み取り、ユーザーの作成 |
| リソース | アクセス対象のシステムオブジェクト | プロジェクト、ドキュメント、設定 |
| アクション | リソースに対する操作 | 作成、読み取り、更新、削除 |

### 組み込みロール

| ロール | 説明 | 編集可能 | 削除可能 |
|--------|------|---------|---------|
| システム管理者 | すべてのリソースへのフルアクセス | いいえ | いいえ |
| プロジェクトマネージャー | プロジェクト範囲内の管理 | はい | いいえ |
| 編集者 | コンテンツの作成と編集 | はい | はい |
| 一般ユーザー | 基本的な使用権限 | はい | いいえ |
| 閲覧者 | 読み取り専用アクセス | はい | はい |

## 権限設定

### 権限マトリックス

| リソース | 作成 | 読み取り | 更新 | 削除 | 管理 |
|---------|------|---------|------|------|------|
| プロジェクト | ✓ | ✓ | ✓ | ✓ | ✓ |
| ドキュメント | ✓ | ✓ | ✓ | ✓ | - |
| タスク | ✓ | ✓ | ✓ | ✓ | - |
| ユーザー | ✓ | ✓ | ✓ | ✓ | ✓ |
| システム設定 | - | ✓ | ✓ | - | ✓ |
| 監査ログ | - | ✓ | - | - | - |

### 権限の継承

権限は上位レベルから下位レベルに継承されます：

- **組織レベル**：組織全体のデフォルト権限
- **プロジェクトレベル**：特定プロジェクト内の権限
- **リソースレベル**：個別リソースに対する細かい権限

:::tip
下位レベルでは、上位レベルで拒否された権限を拡張することはできません。
:::

## カスタムロール

組織固有の要件に合わせてカスタムロールを作成できます。

### カスタムロールの作成

1. **権限** > **ロール一覧**に移動
2. **＋新規ロールを作成**をクリック
3. ロール情報を入力：
   - **ロール名**：識別可能な名前
   - **説明**：目的と範囲
   - **ベースロール**：権限をコピーする既存ロール（任意）
4. マトリックスから必要な権限を選択
5. **作成**をクリック

### ベストプラクティス

:::tip
カスタムロール作成時は以下の原則に従ってください：

- **最小権限の原則**：必要最小限の権限のみを付与
- **職務分離**：相反する責任を異なるロールに分離
- **定期的なレビュー**：四半期ごとにロールと権限を見直し
- **命名規則**：ロール名に目的と範囲を明確に表現
:::
