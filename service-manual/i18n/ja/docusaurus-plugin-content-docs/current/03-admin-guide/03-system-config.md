# システム設定

このガイドでは、グローバル設定、セキュリティポリシー、バックアップとリストア手順、ログ管理を含むシステム全体の設定をご案内します。

## グローバル設定

### 一般設定

| 設定項目 | 説明 | デフォルト |
|---------|------|-----------|
| サイト名 | システムの表示名 | サービスマニュアル |
| デフォルト言語 | デフォルトの表示言語 | 韓国語（ko） |
| タイムゾーン | 日時表示の基準 | Asia/Seoul（UTC+9） |
| 日付形式 | 日付の表示形式 | YYYY-MM-DD |
| セッションタイムアウト | 非アクティブ時の自動ログアウト | 30分 |
| 最大アップロードサイズ | ファイルアップロードの最大サイズ | 50MB |

### 設定の変更

1. **管理パネル** > **システム設定** > **一般**に移動
2. 変更したい設定値を修正
3. **保存**をクリック
4. 一部の設定はシステムの再起動が必要

:::note
再起動が必要な設定には通知メッセージが表示されます。再起動するまで以前の設定が有効です。
:::

## セキュリティポリシー

### パスワードポリシー

| ポリシー | 説明 | 推奨値 |
|---------|------|--------|
| 最小文字数 | 最小文字数 | 8文字以上 |
| 複雑さ | 文字種の要件 | 3種類以上の組み合わせ |
| 有効期限 | パスワード変更間隔 | 90日 |
| 履歴制限 | 最近のパスワードの再利用を防止 | 直近5件 |
| ロックアウト閾値 | 失敗後のアカウントロック | 5回失敗 |
| ロックアウト期間 | 自動解除までの待機時間 | 30分 |

### 二要素認証（2FA）

1. **セキュリティポリシー** > **二要素認証**に移動
2. 認証方法を選択：
   - **TOTP**：時間ベースのワンタイムパスワード（Google Authenticatorなど）
   - **SMS**：テキストメッセージによる確認コード
   - **メール**：メールによる確認コード
3. 適用範囲を設定：
   - 全ユーザーに必須
   - 管理者ロールのみ必須
   - 任意

### IPアクセス制御

特定のIPアドレスまたは範囲にシステムアクセスを制限できます：

| 設定 | 説明 |
|------|------|
| ホワイトリスト | アクセスを許可するIPアドレス/範囲 |
| ブラックリスト | アクセスをブロックするIPアドレス/範囲 |
| 管理者専用IP | 管理パネルへのアクセスを特定IPに制限 |

## バックアップとリストア

### 自動バックアップ設定

| 設定項目 | 説明 | 推奨値 |
|---------|------|--------|
| 頻度 | バックアップ実行間隔 | 毎日 |
| 時刻 | バックアップ実行時刻 | 午前3:00 |
| 保持期間 | バックアップファイルの保持期間 | 30日 |
| 範囲 | バックアップに含むデータ | フル（DB＋ファイル） |
| 保存場所 | バックアップの保存パス | /backup または外部ストレージ |

### バックアップの種類

- **フルバックアップ**：データベースとアップロードファイルを含む完全バックアップ
- **増分バックアップ**：前回のバックアップ以降に変更されたデータのみ
- **設定バックアップ**：システム設定ファイルのみ

:::tip
システムアップデートや大規模な設定変更の前には、必ず手動バックアップを実行してください。
:::

## ログ管理

### ログの種類

| ログ種類 | 説明 | 保持期間 |
|---------|------|---------|
| アクセスログ | ユーザーのログイン/ログアウト記録 | 1年 |
| アクティビティログ | ユーザーのアクション記録 | 6ヶ月 |
| システムログ | システムイベントとエラー | 3ヶ月 |
| セキュリティログ | セキュリティイベント（ログイン失敗など） | 1年 |
| 監査ログ | 権限と設定の変更 | 2年 |

### ログの閲覧

1. **システム設定** > **ログ管理**に移動
2. ログの種類を選択
3. フィルター条件を設定：
   - **期間**：日付範囲
   - **ユーザー**：特定ユーザーのログ
   - **イベント種類**：特定のイベント
   - **重要度**：情報、警告、エラー、重大
4. **検索**をクリック
