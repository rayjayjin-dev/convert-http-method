# インストール

本ドキュメントでは、サービスのインストールと初期設定の手順をご案内します。

## システム要件

サービスを快適に動作させるための最小システム要件：

### ハードウェア要件

| 項目 | 最小 | 推奨 |
|------|------|------|
| CPU | 2コア以上 | 4コア以上 |
| メモリ | 4GB RAM | 8GB以上 RAM |
| ディスク | 20GB空き容量 | 50GB以上空き容量 |
| ネットワーク | 10Mbps | 100Mbps以上 |

### ソフトウェア要件

- **OS**：Windows 10以上、macOS 12以上、Ubuntu 20.04以上
- **ブラウザ**：Chrome 90以上、Firefox 88以上、Safari 14以上、Edge 90以上
- **Node.js**：18.x以上（サーバーインストール用）
- **データベース**：PostgreSQL 14以上またはMySQL 8.0以上

## インストール手順

### ステップ1：インストールファイルのダウンロード

公式ダウンロードページからお使いのOSに対応したインストーラーをダウンロードします。

```bash
# Linux/macOS
curl -fsSL https://example.com/install.sh | bash

# またはパッケージマネージャーを使用
npm install -g @example/service-cli
```

### ステップ2：依存関係のインストール

プロジェクトディレクトリで必要な依存関係をインストールします。

```bash
cd my-project
npm install
```

### ステップ3：環境設定

環境設定ファイルを作成し、必要な値を入力します。

```bash
cp .env.example .env
```

主要な環境変数：

| 変数 | 説明 | デフォルト |
|------|------|-----------|
| `APP_PORT` | サービスポート番号 | 3000 |
| `DB_HOST` | データベースホスト | localhost |
| `DB_PORT` | データベースポート | 5432 |
| `DB_NAME` | データベース名 | service_db |
| `SECRET_KEY` | 暗号化キー | （必須） |

### ステップ4：データベースの初期化

データベーススキーマを作成し、初期データを設定します。

```bash
npm run db:migrate
npm run db:seed
```

### ステップ5：サービスの起動

すべての設定が完了したら、サービスを起動します。

```bash
# 開発モード
npm run dev

# 本番モード
npm run start
```

## 初期設定

サービスを初めて起動した後、以下の設定を完了してください：

1. **管理者アカウントの作成**：初回アクセス時に管理者アカウントを設定
2. **組織情報の入力**：組織名、ロゴ、デフォルト設定を構成
3. **ユーザーの招待**：チームメンバーを招待しロールを割り当て
4. **通知の設定**：メールと通知チャネルを設定

## インストールの確認

以下のコマンドを実行してインストールを確認します：

```bash
npm run health-check
npm run version
```

正常にインストールされていれば、ブラウザで `http://localhost:3000` にアクセスするとログイン画面が表示されます。
