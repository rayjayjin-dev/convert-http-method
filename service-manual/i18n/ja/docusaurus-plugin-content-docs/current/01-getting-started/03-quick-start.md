# クイックスタートガイド

このガイドでは、インストール後すぐに使い始める方法をご案内します。以下の手順に従って、5分以内に最初のタスクを完了しましょう。

## 前提条件

開始前に以下を確認してください：

- [x] サービスのインストールが完了している
- [x] 管理者アカウントが作成されている
- [x] ブラウザからサービスにアクセスできる

## ステップ1：ログイン

1. ブラウザでサービスURLにアクセスします
2. 管理者アカウントまたは招待されたアカウントでログインします
3. ダッシュボード画面が表示されればログイン成功です

:::tip
初回ログイン時にパスワードを変更することをお勧めします。
:::

## ステップ2：最初のプロジェクトを作成

ログイン後、最初のプロジェクトを作成します。

1. 左メニューの**プロジェクト**をクリック
2. **新規プロジェクト作成**ボタンをクリック
3. プロジェクト情報を入力：
   - **プロジェクト名**：プロジェクトの名前を入力
   - **説明**：簡単な説明を記入
   - **公開範囲**：チーム全体または特定メンバーへのアクセスを設定
4. **作成**をクリックしてプロジェクトを確定

## ステップ3：チームメンバーを招待

チームメンバーを招待してプロジェクトでのコラボレーションを開始します。

1. プロジェクト設定ページに移動
2. **メンバー**タブを選択
3. **メンバーを招待**をクリック
4. チームメンバーのメールアドレスを入力
5. ロールを選択：

| ロール | 権限 |
|--------|------|
| 閲覧者 | 読み取り専用アクセス |
| 編集者 | 読み取りおよび書き込みアクセス |
| 管理者 | フルアクセス |

## ステップ4：最初のタスクを作成

プロジェクト内で最初のタスクを作成します。

1. プロジェクトダッシュボードで**タスクを追加**をクリック
2. タスク情報を入力：
   - **タイトル**：タスクのタイトルを入力
   - **担当者**：チームメンバーを割り当て
   - **期限**：締め切りを設定
   - **優先度**：高、中、低から選択
3. **保存**をクリック

:::note
タスクは作成後いつでも変更できます。
:::

## ステップ5：結果の確認

プロジェクトとタスクがダッシュボードに正しく表示されていることを確認します。

- ダッシュボードでプロジェクトのステータスを確認
- タスクリストでタスクのステータスを確認
- チームメンバーが招待メールを受信したことを確認
