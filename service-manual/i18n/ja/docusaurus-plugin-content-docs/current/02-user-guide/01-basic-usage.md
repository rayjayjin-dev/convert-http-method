# 基本的な使い方

このガイドでは、ダッシュボードのナビゲーションからプロジェクトおよびタスク管理まで、サービスのコア機能を効果的に使用するための基本操作をご案内します。

## ダッシュボード

ダッシュボードはログイン後に最初に表示される画面です。主要な指標と最近のアクティビティの概要を提供します。

### ダッシュボードの構成要素

| コンポーネント | 説明 | 位置 |
|---------------|------|------|
| サマリーカード | プロジェクト数、アクティブタスク、完了率などの主要指標 | 上部エリア |
| 最近のアクティビティ | チームメンバーの最近のアクションのタイムライン | 中央左 |
| 通知パネル | 未読通知とメンション | 中央右 |
| クイックアクション | よく使う機能へのショートカットボタン | 下部エリア |

### ダッシュボードのカスタマイズ

ダッシュボードのウィジェットを好みに合わせて並べ替えることができます。

1. 右上の**編集**ボタンをクリック
2. ウィジェットを好みの位置にドラッグ
3. 不要なウィジェットは**×**ボタンで非表示に
4. **保存**をクリックして変更を適用

:::tip
ダッシュボードのレイアウトは個人設定として保存され、デバイス間で維持されます。
:::

## プロジェクト管理

プロジェクトはコアとなる組織単位です。作業をプロジェクトに整理して体系的に管理しましょう。

### プロジェクトの作成

1. 左サイドバーの**プロジェクト**をクリック
2. **＋新規プロジェクト**をクリック
3. プロジェクト情報を入力：
   - **プロジェクト名**：識別可能な名前
   - **説明**：目的と範囲
   - **開始日/終了日**：プロジェクトのタイムライン
   - **チームメンバー**：参加者を選択
4. **作成**をクリック

### プロジェクトビュー

プロジェクトリストは複数の表示モードに対応しています：

- **カードビュー**：ビジュアルなカード形式の表示
- **リストビュー**：詳細情報を含むテーブル形式
- **タイムラインビュー**：スケジュールのガントチャート形式

## タスク管理

タスクはプロジェクト内の個別の作業項目を表します。

### タスクの作成

タスク作成時に利用可能なフィールド：

- **タイトル**：タスク名
- **説明**：詳細内容（Markdown対応）
- **担当者**：責任者となるチームメンバー
- **優先度**：緊急、高、通常、低
- **期限**：完了期限
- **ラベル**：分類用のタグ

### タスクステータスの変更

1. タスクカードをクリックして詳細ビューを開く
2. ドロップダウンから新しいステータスを選択
3. 必要に応じてコメントを追加

:::tip
カンバンビューでは、タスクカードをドラッグ＆ドロップしてステータスを素早く変更できます。
:::

### フィルタリングとソート

さまざまな条件でタスクをフィルタリングできます：

| フィルター | 説明 |
|-----------|------|
| 担当者 | 特定のメンバーに割り当てられたタスクを表示 |
| ステータス | 特定のステータスのタスクを表示 |
| 優先度 | 特定の優先度のタスクを表示 |
| 期限 | 日付範囲内のタスクを表示 |
| ラベル | 特定のラベルのタスクを表示 |
