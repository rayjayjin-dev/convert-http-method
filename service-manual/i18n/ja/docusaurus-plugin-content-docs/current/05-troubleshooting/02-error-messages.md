# エラーメッセージ

このガイドでは、サービス利用中に表示される可能性のあるエラーメッセージとその解決方法をご案内します。各エラーコードの原因と解決方法を確認してください。

## エラーメッセージの形式

サービスのエラーメッセージは以下の形式に従います：

```
[エラーコード] エラーの説明
例：[E1001] 認証に失敗しました。メールアドレスまたはパスワードを確認してください。
```

:::tip
エラーコードを記録しておくと、テクニカルサポートへの問い合わせ時に迅速な解決に役立ちます。
:::

## 認証エラー（E1xxx）

| コード | メッセージ | 原因 | 解決方法 |
|--------|----------|------|---------|
| E1001 | 認証に失敗しました | メールまたはパスワードの不一致 | 認証情報を確認して再試行 |
| E1002 | アカウントがロックされています | 5回連続のログイン失敗 | 30分待つか管理者に連絡 |
| E1003 | セッションが期限切れです | 長時間の非アクティブ | 再度ログイン |
| E1004 | アクセスが拒否されました | 権限不足 | 管理者に権限をリクエスト |
| E1005 | トークンが無効です | APIトークンの期限切れまたは失効 | 新しいトークンを発行 |
| E1006 | 二要素認証が必要です | セキュリティポリシーで2FAが必須 | 認証アプリでコードを確認 |

### E1001：認証に失敗しました

**詳細：**

ログイン時に入力したメールアドレスまたはパスワードが登録情報と一致しない場合に発生します。

**解決手順：**

1. メールアドレスの入力ミスを確認
2. Caps Lockが無効であることを確認
3. パスワードのリセットを試行
4. ソーシャルログインで作成されたアカウントかどうかを確認

## データエラー（E2xxx）

| コード | メッセージ | 原因 | 解決方法 |
|--------|----------|------|---------|
| E2001 | データが見つかりません | リクエストされたリソースが存在しない | URLまたはIDを確認 |
| E2002 | データの保存に失敗しました | サーバーストレージエラー | しばらくしてから再試行 |
| E2003 | 入力が無効です | 必須フィールドの不足またはフォーマットエラー | 入力フォームを確認 |
| E2004 | 重複データが存在します | 一意フィールドの値が競合 | 別の値を使用 |
| E2005 | データサイズを超過しました | 入力が許容限度を超過 | データサイズを削減 |

## ファイルエラー（E3xxx）

| コード | メッセージ | 原因 | 解決方法 |
|--------|----------|------|---------|
| E3001 | ファイルのアップロードに失敗しました | ネットワークまたはサーバーエラー | ネットワークを確認して再試行 |
| E3002 | ファイルサイズを超過しました | 最大許容サイズを超過 | ファイルを圧縮または分割 |
| E3003 | サポートされていないファイル形式です | ファイル拡張子が許可されていない | サポートされる形式に変換 |
| E3004 | ストレージ容量が不足しています | ストレージクォータを超過 | ファイルを削除またはプランをアップグレード |

### E3002：ファイルサイズを超過しました

**プラン別ファイルサイズ制限：**

| プラン | 最大単一ファイル | 日次アップロード制限 |
|--------|----------------|-------------------|
| Basic | 50MB | 500MB |
| Pro | 100MB | 2GB |
| Enterprise | 500MB | 無制限 |

## ネットワークエラー（E4xxx）

| コード | メッセージ | 原因 | 解決方法 |
|--------|----------|------|---------|
| E4001 | サーバーに接続できません | ネットワーク切断 | インターネット接続を確認 |
| E4002 | リクエストがタイムアウトしました | サーバーレスポンスの遅延 | しばらくしてから再試行 |
| E4003 | リクエスト制限を超過しました | APIレート制限に到達 | 待ってから再試行 |
| E4004 | サービスはメンテナンス中です | 定期/緊急メンテナンス | メンテナンス後に再試行 |

## エラーコードクイックリファレンス

| コード範囲 | カテゴリ | 主なアクション |
|-----------|---------|--------------|
| E1xxx | 認証/権限 | ログイン情報を確認、権限をリクエスト |
| E2xxx | データ | 入力値を確認、データの整合性を検証 |
| E3xxx | ファイル | ファイルサイズ/形式を確認 |
| E4xxx | ネットワーク | 接続を確認、再試行 |
| E5xxx | システム | 管理者に連絡、後で再試行 |
