# レート制限

サービスの安定性を確保するため、APIリクエストにはレート制限が適用されます。本ドキュメントでは、制限ポリシー、レスポンスヘッダー、制限超過時の対応手順をご案内します。

## レート制限ポリシー

### プラン別制限

| プラン | リクエスト/分 | 日次リクエスト | 同時接続数 |
|--------|-------------|--------------|-----------|
| Free | 60 | 1,000 | 5 |
| Basic | 300 | 10,000 | 20 |
| Pro | 1,000 | 100,000 | 50 |
| Enterprise | 5,000 | 無制限 | 200 |

### エンドポイント別制限

一部のエンドポイントには追加の制限があります：

| エンドポイント | 制限 | 適用単位 |
|--------------|------|---------|
| `POST /oauth/token` | 10回/分 | IPアドレス |
| `POST /api/v1/users` | 30回/分 | APIキー |
| `GET /api/v1/search` | 30回/分 | APIキー |
| `POST /api/v1/webhooks` | 5回/分 | APIキー |
| `DELETE /api/v1/*` | 60回/分 | APIキー |

## レスポンスヘッダー

すべてのAPIレスポンスにはレート制限ステータスヘッダーが含まれます：

```http
HTTP/1.1 200 OK
X-RateLimit-Limit: 300
X-RateLimit-Remaining: 295
X-RateLimit-Reset: 1705312260
X-RateLimit-Policy: basic
```

### ヘッダーの説明

| ヘッダー | 説明 | 例 |
|---------|------|-----|
| `X-RateLimit-Limit` | 現在のウィンドウでの最大リクエスト数 | `300` |
| `X-RateLimit-Remaining` | 残りリクエスト数 | `295` |
| `X-RateLimit-Reset` | リセット時刻（Unixタイムスタンプ） | `1705312260` |
| `X-RateLimit-Policy` | 適用されたポリシー名 | `basic` |
| `Retry-After` | 待機時間（秒）（429のみ） | `30` |

## 制限超過時の対応

### 429レスポンス形式

```json
{
  "success": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "レート制限を超過しました。しばらくしてから再試行してください。",
    "details": {
      "limit": 300,
      "window": "1m",
      "retry_after": 30,
      "reset_at": "2024-01-15T10:31:00Z"
    }
  }
}
```

### 防止戦略

| 戦略 | 説明 | 効果 |
|------|------|------|
| リクエストバッチ処理 | 複数のリクエストを1つにまとめる | リクエスト数の削減 |
| キャッシュ | レスポンスデータをローカルにキャッシュ | 重複リクエストの排除 |
| リクエストキュー | リクエストをキューに入れて順次処理 | バーストの防止 |
| Webhook | ポーリングの代わりにWebhookでイベントを受信 | ポーリングの排除 |
| 条件付きリクエスト | `If-Modified-Since` ヘッダーを使用 | 不要な転送の削減 |

:::tip
`X-RateLimit-Remaining` を監視し、残り数が制限の10%を下回ったらリクエストを抑制してください。
:::

## クォータ管理

### 日次クォータ

日次クォータはUTC 00:00にリセットされます。

### アラート設定

クォータ使用量の閾値に基づいてアラートを設定できます：

| 閾値 | アラート方法 | 説明 |
|------|------------|------|
| 50% | メール | 日次クォータの50%を使用 |
| 80% | メール + Webhook | 日次クォータの80%を使用 |
| 90% | メール + Webhook + SMS | 日次クォータの90%を使用 |
| 100% | メール + Webhook + SMS | クォータ超過 |

:::warning
クォータを超過するとすべてのAPIリクエストが拒否されます。重要なサービスには80%閾値のアラートを設定し、必要に応じてプランのアップグレードを検討してください。
:::
