# よくある問題

このガイドでは、よく発生する問題とその解決方法をご案内します。各問題について、症状、原因、解決手順を確認してください。

## ログインの問題

### ログインできない

**症状：** 正しいメールアドレスとパスワードを入力してもログインに失敗する。

**原因：**
- Caps Lockが有効になっている
- アカウントが無効化またはロックされている
- ブラウザのキャッシュ/Cookieの問題

**解決方法：**

1. Caps Lockがオフであることを確認
2. パスワードのリセットを試行
3. ブラウザのキャッシュとCookieをクリア
4. シークレット/プライベートモードでログインを試行

:::tip
5回連続でログインに失敗すると、アカウントは自動的にロックされます。30分待つか、管理者に連絡してロックを解除してください。
:::

### セッションが頻繁に切れる

**症状：** 作業中に予期せずログアウトされる、またはセッション期限切れのメッセージが表示される。

**原因：**
- セキュリティポリシーのセッションタイムアウト
- 複数デバイスからの同時ログイン
- 不安定なネットワーク接続

**解決方法：**

1. システム設定のセッションタイムアウト設定を確認
2. 他のデバイスからログアウト
3. 「ログイン状態を維持」オプションを有効にする

## パフォーマンスの問題

### ページの読み込みが遅い

**症状：** ページ遷移に5秒以上かかる。

**原因：**
- ネットワーク帯域幅の不足
- ブラウザ拡張機能の競合
- サーバー負荷の増加
- ローカルキャッシュの破損

**解決方法：**

1. ネットワーク接続を確認
2. 不要なブラウザ拡張機能を無効化
3. ブラウザキャッシュをクリアしてリフレッシュ
4. 別のブラウザでテスト

```bash
# ネットワーク接続の確認
ping api.example.com
traceroute api.example.com
```

## 接続エラー

### サーバーに接続できない

**症状：** 「サーバーに接続できません」または「ネットワークエラー」のメッセージが表示される。

**原因：**
- インターネット接続の切断
- サーバーメンテナンス中
- ファイアウォールまたはプロキシ設定の問題
- DNS解決の失敗

**解決方法：**

1. インターネット接続を確認
2. サービスステータスページでメンテナンス情報を確認
3. VPNを使用している場合は無効にして再試行
4. DNS設定を確認

:::warning
企業ネットワークでは、ファイアウォールポリシーが特定のポートをブロックしている場合があります。IT部門に連絡して、必要なポート（443、8080）が開放されていることを確認してください。
:::

## データ同期の問題

### データが同期されない

**症状：** あるデバイスで行った変更が別のデバイスに反映されない。

**原因：**
- 同期サービスが一時的に停止
- 競合する変更が存在
- ストレージ容量の不足
- オフライン変更後の同期失敗

**解決方法：**

1. 同期ステータスアイコンを確認（🔄 同期中、✅ 完了、⚠️ エラー）
2. 手動同期を実行：**設定 > 同期 > 今すぐ同期**
3. 競合解決画面で競合を解決
4. ストレージ容量を確認し、不要なファイルを削除

:::tip
デフォルトの自動同期間隔は5分です。リアルタイム同期が必要な場合は、**設定 > 同期 > 同期間隔**で1分に変更してください。
:::

## 問題が解決しない場合

上記の解決方法で問題が解決しない場合は、以下の情報を添えてテクニカルサポートにお問い合わせください：

1. **発生日時** - 正確な日付と時刻
2. **環境** - OS、ブラウザの種類とバージョン
3. **再現手順** - 問題を再現するための具体的な手順
4. **エラーメッセージ** - 完全なエラーメッセージのテキスト
5. **スクリーンショット** - 問題を示す画面キャプチャ
