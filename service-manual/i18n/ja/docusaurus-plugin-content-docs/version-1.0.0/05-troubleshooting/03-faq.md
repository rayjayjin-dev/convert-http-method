# よくある質問（FAQ）

サービスに関するよくある質問と回答をカテゴリ別にまとめています。

## アカウント

### 新規登録するにはどうすればよいですか？

サービスのホームページで**新規登録**ボタンをクリックし、以下を入力してください：

1. メールアドレス（ログインIDとして使用）
2. パスワード（8文字以上、英字＋数字＋特殊文字）
3. 名前と組織情報
4. 利用規約への同意

登録後に確認メールが送信されます。メール認証を完了するとサービスにアクセスできます。

:::tip
会社のメールアドレスで登録すると、組織のワークスペースに自動的に招待される場合があります。
:::

### パスワードを忘れました。リセットするにはどうすればよいですか？

1. ログインページで**パスワードを忘れた方**をクリック
2. 登録時に使用したメールアドレスを入力
3. メールに送信されたリセットリンクをクリック
4. 新しいパスワードを設定

:::note
パスワードリセットリンクの有効期限は24時間です。期限切れの場合は新しいリンクをリクエストしてください。
:::

### アカウントを削除したい

アカウントの削除は**設定 > アカウント > アカウント削除**から行えます。

:::warning
アカウントの削除はすべてのデータを永久に削除し、元に戻すことはできません。削除前に必要なデータをバックアップしてください。削除リクエスト後30日間の猶予期間があり、この期間中にログインすると削除がキャンセルされます。
:::

## 機能

### 対応ブラウザは何ですか？

以下のブラウザの最新2バージョンを公式にサポートしています：

| ブラウザ | 最小バージョン | 推奨 |
|---------|--------------|------|
| Chrome | 90以上 | 最新版 |
| Firefox | 88以上 | 最新版 |
| Safari | 14以上 | 最新版 |
| Edge | 90以上 | 最新版 |

:::note
Internet Explorerはサポートされていません。モバイルブラウザ（Chrome Mobile、Safari Mobile）はサポートされています。
:::

### オフラインで使用できますか？

限定的な機能がオフラインで利用可能です：

- ✅ 以前開いたドキュメントの閲覧
- ✅ ローカルに保存されたタスクの編集
- ✅ キャッシュされたデータの検索
- ❌ 新しいデータの同期
- ❌ リアルタイム通知の受信
- ❌ ファイルのアップロード/ダウンロード

オフラインで行った変更は、オンラインに戻ると自動的に同期されます。

### データをエクスポートできますか？

はい、以下の形式でデータをエクスポートできます：

- **CSV** - スプレッドシート互換形式
- **JSON** - プログラミング連携形式
- **PDF** - ドキュメントアーカイブ形式

エクスポート場所：**設定 > データ管理 > エクスポート**

## 料金

### 利用可能な料金プランは何ですか？

| プラン | 月額料金 | ユーザー数 | ストレージ | 主な機能 |
|--------|---------|-----------|-----------|---------|
| Free | 無料 | 最大3名 | 1GB | 基本機能 |
| Basic | $9.90/ユーザー | 最大10名 | 5GB | 高度な検索、エクスポート |
| Pro | $19.90/ユーザー | 最大50名 | 50GB | APIアクセス、カスタムロール |
| Enterprise | お問い合わせ | 無制限 | 無制限 | 専用サポート、SLA |

:::note
年間契約で20%割引が適用されます。すべての有料プランには14日間の無料トライアルが含まれます。
:::

### プランを変更したい

**設定 > 請求 > プラン変更**からいつでもプランを変更できます。

- **アップグレード**：即座に適用、日割り計算で請求
- **ダウングレード**：現在の請求サイクル終了時に適用

## 技術

### API連携を始めるにはどうすればよいですか？

1. **設定 > API > APIキー**でAPIキーを生成
2. [認証ガイド](/docs/api-reference/authentication)に従って認証を設定
3. [エンドポイント一覧](/docs/api-reference/endpoints)で利用可能なAPIを確認

```bash
# API接続テスト
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.example.com/v1/health
```

### サービスの可用性（SLA）はどのくらいですか？

| プラン | SLA | 月間許容ダウンタイム |
|--------|-----|-------------------|
| Free / Basic | 99.5% | 約3.6時間 |
| Pro | 99.9% | 約43分 |
| Enterprise | 99.95% | 約22分 |

### データはどこに保存されますか？

- **プライマリリージョン**：韓国（ソウル）
- **バックアップリージョン**：日本（東京）
- **暗号化**：AES-256（保存時および転送時）
- **バックアップ頻度**：毎日自動バックアップ、30日間保持
