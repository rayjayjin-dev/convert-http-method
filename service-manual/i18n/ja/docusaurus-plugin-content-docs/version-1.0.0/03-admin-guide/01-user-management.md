# ユーザー管理

このガイドでは、システムに登録されたユーザーの効果的な管理方法をご案内します。ユーザーの追加・削除、ロール割り当て、ユーザーリスト管理、一括操作について説明します。

## ユーザーの追加

### 個別ユーザー登録

1. 管理パネルの**ユーザー管理**に移動
2. **＋ユーザーを追加**をクリック
3. ユーザー情報を入力：
   - **メール**：ログイン用メールアドレス
   - **名前**：表示名
   - **部署**：所属部署を選択
   - **ロール**：割り当てるロールを選択
4. **招待メールを送信**にチェック
5. **保存**をクリックして登録完了

:::tip
招待メールにより、ユーザーは自分でパスワードを設定できます。招待リンクの有効期限は72時間です。
:::

### 必須フィールド

| フィールド | 必須 | 説明 |
|-----------|------|------|
| メール | はい | ログインIDとして使用、一意である必要あり |
| 名前 | はい | システム内の表示名 |
| 部署 | いいえ | 組織の部署 |
| ロール | はい | アクセス権限を決定 |
| 電話番号 | いいえ | 2FAおよび通知用 |

## ユーザーの削除

### 削除プロセス

1. **ユーザー管理**リストから削除するユーザーを選択
2. 上部メニューの**削除**をクリック
3. 削除オプションを選択：
   - **即時削除**：アカウントを即座に無効化
   - **猶予期間**：30日後に自動削除（復元可能）
4. **確認**をクリック

:::warning
即時削除されたユーザーのデータは復元できません。重要なデータがあるアカウントには猶予期間付き削除を使用してください。
:::

### 削除時のデータ処理

| データ種類 | 処理方法 |
|-----------|---------|
| 個人設定 | 削除 |
| 作成したドキュメント | アーカイブ（管理者がアクセス可能） |
| プロジェクト履歴 | アーカイブ |
| コメント・アクティビティログ | 匿名化してアーカイブ |
| アップロードファイル | プロジェクト所有に移管 |

## ロール割り当て

適切なロールを割り当ててユーザーのアクセス権限を管理します。

### デフォルトロール

| ロール | 説明 | 主要権限 |
|--------|------|---------|
| システム管理者 | システム全体の管理 | すべての機能 |
| プロジェクトマネージャー | プロジェクトレベルの管理 | プロジェクトの作成/削除、メンバー管理 |
| 一般ユーザー | 基本的な使用権限 | タスクの作成/編集、ドキュメントの閲覧 |
| 閲覧者 | 読み取り専用アクセス | コンテンツの閲覧のみ |

### ロールの変更

1. ユーザーリストで対象ユーザーをクリック
2. **ロール**タブを選択
3. ドロップダウンから新しいロールを選択
4. **変更理由**を入力（監査ログ用）
5. **適用**をクリック

## 一括操作

### 一括ユーザー登録

CSVファイルを使用して複数のユーザーを一度に登録できます。

```csv
email,name,department,role
user1@example.com,田中太郎,エンジニアリング,一般ユーザー
user2@example.com,佐藤花子,マーケティング,一般ユーザー
user3@example.com,鈴木一郎,デザイン,プロジェクトマネージャー
```

### 一括操作の種類

| 操作 | 説明 | 最大件数 |
|------|------|---------|
| 一括登録 | CSVでユーザーを登録 | 500件 |
| 一括ロール変更 | 選択したユーザーのロールを変更 | 100件 |
| 一括無効化 | 選択したユーザーを無効化 | 100件 |
| 一括削除 | 選択したユーザーを削除 | 50件 |
| 一括再招待 | 保留中のユーザーに招待を再送 | 200件 |
