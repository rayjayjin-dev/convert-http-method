# 高度な機能

高度な機能を活用して、繰り返しタスクの自動化、複雑なワークフローの構築、外部ツールとの連携を行い、生産性を最大化しましょう。

## 自動化ルール

特定の条件が満たされたときに自動的にアクションを実行する自動化ルールを設定できます。

### 自動化ルールの作成

1. **プロジェクト設定** → **自動化**タブに移動
2. **＋新規ルール**をクリック
3. トリガー条件とアクションを設定

### トリガーの種類

| トリガー | 説明 | 例 |
|---------|------|-----|
| ステータス変更 | タスクのステータスが変更されたとき | タスクが「完了」に移動 |
| 担当者変更 | タスクの担当者が変更されたとき | 新しい担当者が割り当てられた |
| 期限接近 | 締め切りが近づいたとき | 期限の3日前 |
| ラベル追加 | 特定のラベルが追加されたとき | 「緊急」ラベルが追加された |
| コメント追加 | 新しいコメントが投稿されたとき | メンションを含むコメント |

### 利用可能なアクション

トリガー条件が満たされると、以下のアクションが自動的に実行されます：

- チームメンバーの自動割り当て
- ステータスの自動変更
- 通知の送信
- ラベルの自動追加/削除
- サブタスクの自動作成

## ワークフロー設定

ワークフローは、タスクが通過すべきステージを定義します。プロジェクトのニーズに合わせてワークフローをカスタマイズできます。

### デフォルトワークフロー

```
未着手 → 進行中 → レビュー中 → 完了
```

### カスタムワークフロー

1. **プロジェクト設定** → **ワークフロー**タブに移動
2. **＋新規ワークフロー**をクリック
3. ステージを追加し、遷移ルールを設定

```
企画 → デザイン → 開発 → QA → デプロイ → 完了
```

## 外部連携

外部サービスを接続して作業環境を統合できます。

### 対応する連携サービス

| サービス | 機能 | 設定方法 |
|---------|------|---------|
| Slack | 通知、タスク作成 | Webhook URL |
| GitHub | コミット連携、PR同期 | OAuth |
| Google Calendar | 期限同期 | APIキー |
| Jira | 双方向イシュー同期 | APIトークン |
| メール | メールからタスク作成 | 専用メールアドレス |

### Webhook設定

```json
{
  "url": "https://api.example.com/webhooks/incoming",
  "events": ["task.created", "task.updated", "task.completed"],
  "secret": "your-webhook-secret"
}
```

:::tip
Webhookイベントは最大3回リトライされます。5秒以内にレスポンスがないリクエストはタイムアウトとして処理されます。
:::

## 高度なフィルタリングと検索

複雑な条件を組み合わせて、必要なものを正確に見つけることができます。

### フィルターの組み合わせ

AND/OR演算子で複数の条件を組み合わせます：

```
(担当者 = "田中" OR 担当者 = "佐藤")
AND ステータス != "完了"
AND 優先度 = "高"
AND 期限 < "2024-12-31"
```

### 検索構文

| 構文 | 説明 | 例 |
|------|------|-----|
| `""` | 完全一致検索 | `"デプロイ完了"` |
| `AND` | すべての条件を満たす | `バグ AND 緊急` |
| `OR` | いずれかの条件を満たす | `フロントエンド OR バックエンド` |
| `NOT` | 条件を除外 | `バグ NOT 解決済み` |
| `label:` | ラベルで検索 | `label:緊急` |
| `assignee:` | 担当者で検索 | `assignee:tanaka` |
