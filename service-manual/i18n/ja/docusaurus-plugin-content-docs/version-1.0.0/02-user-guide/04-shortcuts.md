# キーボードショートカット

キーボードショートカットを使用して、マウスを使わずにサービスを素早くナビゲートおよび操作できます。このガイドでは、デフォルトのショートカットとカスタムショートカットの設定方法をご案内します。

## 概要

サービスでは以下のカテゴリに分類されたさまざまなキーボードショートカットを提供しています：

- **グローバルショートカット**：どの画面でも利用可能
- **ナビゲーションショートカット**：画面間の移動
- **タスクショートカット**：タスク関連の操作
- **編集ショートカット**：テキストの書式設定

:::tip
`Ctrl + /`（macOS: `⌘ + /`）を押すと、現在の画面で利用可能なショートカットを素早く確認できます。
:::

## グローバルショートカット

### Windows / Linux

| ショートカット | アクション |
|---------------|-----------|
| `Ctrl + K` | クイック検索（コマンドパレット）を開く |
| `Ctrl + /` | ショートカットヘルプを表示 |
| `Ctrl + ,` | 設定を開く |
| `Ctrl + N` | 新規タスクを作成 |
| `Ctrl + Shift + N` | 新規プロジェクトを作成 |
| `Ctrl + B` | サイドバーの表示/非表示 |
| `Ctrl + Shift + F` | グローバル検索 |
| `Escape` | 現在のモーダル/パネルを閉じる |
| `Ctrl + Z` | 最後のアクションを元に戻す |

### macOS

| ショートカット | アクション |
|---------------|-----------|
| `⌘ + K` | クイック検索（コマンドパレット）を開く |
| `⌘ + /` | ショートカットヘルプを表示 |
| `⌘ + ,` | 設定を開く |
| `⌘ + N` | 新規タスクを作成 |
| `⌘ + Shift + N` | 新規プロジェクトを作成 |
| `⌘ + B` | サイドバーの表示/非表示 |
| `⌘ + Shift + F` | グローバル検索 |
| `Escape` | 現在のモーダル/パネルを閉じる |
| `⌘ + Z` | 最後のアクションを元に戻す |

## ナビゲーションショートカット

| Windows/Linux | macOS | アクション |
|---------------|-------|-----------|
| `Alt + 1` | `⌥ + 1` | ダッシュボードへ移動 |
| `Alt + 2` | `⌥ + 2` | プロジェクトへ移動 |
| `Alt + 3` | `⌥ + 3` | マイタスクへ移動 |
| `Alt + 4` | `⌥ + 4` | 通知へ移動 |
| `Alt + 5` | `⌥ + 5` | レポートへ移動 |

## タスクショートカット

### タスクリストビュー

| ショートカット | アクション |
|---------------|-----------|
| `J` / `↓` | 次のタスク |
| `K` / `↑` | 前のタスク |
| `Enter` | 選択したタスクを開く |
| `Space` | タスクの選択/選択解除（複数選択） |
| `X` | 完了としてマーク |
| `D` | 選択したタスクを削除 |
| `L` | ラベルを追加 |
| `A` | 担当者を変更 |
| `P` | 優先度を変更 |

## カスタムショートカット

デフォルトのショートカットを好みに合わせてカスタマイズできます。

### ショートカットの変更

1. **設定** → **ショートカット**タブに移動
2. 変更したいショートカットを見つける
3. **編集**アイコンをクリック
4. 新しいキーの組み合わせを押す
5. **保存**をクリック

### ショートカットのルール

:::warning
- ブラウザのデフォルトショートカットは上書きできません
- 1つのキーの組み合わせを複数のアクションに割り当てることはできません
- グローバルショートカットには少なくとも1つの修飾キー（Ctrl、Alt、Shift）が必要です
:::
