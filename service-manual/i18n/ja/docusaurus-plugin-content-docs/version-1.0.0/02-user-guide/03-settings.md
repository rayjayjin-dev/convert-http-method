# 設定

サービスを作業環境に合わせてカスタマイズできます。プロフィール、通知、テーマ、言語などを設定しましょう。

## 設定画面へのアクセス

設定画面にアクセスするには：

1. 右上の**プロフィールアイコン**をクリック
2. ドロップダウンメニューから**設定**を選択

またはキーボードショートカット `Ctrl + ,`（macOS: `⌘ + ,`）を使用します。

## 個人設定

### プロフィール情報

| 設定項目 | 説明 | 必須 |
|---------|------|------|
| 名前 | サービス内の表示名 | はい |
| メール | ログインおよび通知用メール | はい |
| プロフィール写真 | アバター画像（最大2MB） | いいえ |
| 役職 | 組織内の役職 | いいえ |
| 部署 | 所属部署 | いいえ |
| 電話番号 | 追加の連絡先情報 | いいえ |

### パスワード変更

1. **セキュリティ**タブに移動
2. 現在のパスワードを入力
3. 新しいパスワードを入力して確認
4. **変更**をクリック

:::note
パスワードは8文字以上で、大文字、小文字、数字、特殊文字を含む必要があります。
:::

### 二要素認証（2FA）

セキュリティ強化のために2FAを有効にします：

1. **セキュリティ**タブの**二要素認証**セクションを見つける
2. **有効にする**をクリック
3. 認証アプリ（Google Authenticatorなど）でQRコードをスキャン
4. 6桁のコードを入力して設定を完了

## 通知設定

重要な情報のみを受信するように通知を細かく調整できます。

### 通知チャネル

| チャネル | 説明 | デフォルト |
|---------|------|-----------|
| アプリ内 | 通知センターに表示 | 有効 |
| メール | 登録メールに送信 | 有効 |
| ブラウザプッシュ | ブラウザプッシュ通知 | 無効 |
| Slack | 接続されたSlackチャネルに送信 | 無効 |

### イベント別設定

| イベント | アプリ内 | メール | プッシュ |
|---------|---------|--------|---------|
| タスク割り当て | ✅ | ✅ | ✅ |
| ステータス変更 | ✅ | ❌ | ❌ |
| コメントメンション | ✅ | ✅ | ✅ |
| 期限リマインダー | ✅ | ✅ | ✅ |
| プロジェクト招待 | ✅ | ✅ | ❌ |

## テーマ設定

サービスの外観をカスタマイズできます。

### テーマモード

| モード | 説明 |
|--------|------|
| ライト | デフォルトの明るい背景テーマ |
| ダーク | 暗い背景テーマ |
| システム | OSの設定に自動的に従う |

### テーマの変更

1. **外観**タブに移動
2. 好みのテーマモードを選択
3. 変更は即座に適用されます

## 言語設定

サービスインターフェースの表示言語を変更できます。

### 対応言語

| 言語 | コード | カバレッジ |
|------|--------|-----------|
| 한국어 | ko | 完全対応 |
| English | en | 完全対応 |
| 日本語 | ja | UI対応 |
| 中文 | zh | UI対応 |

### 言語の変更

1. **一般**タブの**言語**セクションを見つける
2. ドロップダウンから好みの言語を選択
3. **保存**をクリック
4. 選択した言語でページが更新されます
