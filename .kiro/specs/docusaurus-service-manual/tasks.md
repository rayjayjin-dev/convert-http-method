## 참고 사항

- 각 태스크는 이전 태스크의 결과물에 의존하므로 순서대로 실행해야 합니다
- 체크포인트에서 빌드 검증을 통해 점진적으로 오류를 발견하고 수정합니다
- 설계 문서에 PBT(Property-Based Testing)가 비적용으로 명시되어 있으므로 별도의 속성 기반 테스트 태스크는 포함하지 않습니다
- 모든 코드 예제는 TypeScript로 작성합니다
- 새 페이지 추가 시 사이드바 자동 생성 설정으로 인해 수동 설정 변경이 불필요합니다
